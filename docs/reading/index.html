雅思阅读 — 题型技巧速查

11 大官方题型逐个击破：每类给出形式、3–6 条具体策略、1 个 30 秒可立刻做的动作。文末 5 条黄金策略贯穿全场。

Type 1. Multiple choice（单选/多选）

题型形式：4 选 1 单选或 7 选 N 多选；常见于 Passage 2 / Passage 3；题量通常 4–6 题。

  • 先题后文：先把题干中的人名、数字、大写专有名词圈出来作为定位锚。
  • 排除极端词：含 all / never / every / must 的选项 90% 是错的；含 may / sometimes / often / likely 多为正解。
  • 同义替换是正解：答案选项与原文是同义替换关系，绝不原词重复。
  • "半对半错"陷阱：选项里既有原文原词又有改写词 = 干扰项，找那个被偷偷换掉的词。
  • 多选独立判断：多选题每个选项独立判 True/False，不要因前一个选 A 就觉得下一个不会也是 A。
  • 拿不准选最短：经验法则——两个选项都像正解时，答案常是更短更直白的那个。

30 秒动作：圈题干里的大写人名 / 数字 / 专有名词 → 再扫选项尾部，画掉含 never / all 的选项。

Type 2. Identifying information（True / False / Not Given）

题型形式：判断陈述是否与原文一致；常见于 Passage 2 / Passage 3；题量通常 4–7 题。

  • NG 与 F 严格区分：NG = 信息未提及（原文根本没说）；F = 信息与原文矛盾（原文说反了）。
  • 用"硬词"定位：题干中的数字 / 大写 / 年份是定位锚；抽象词（important / develop）不能定位。
  • 范围篡改检测：原文说 "some / many" → 题干写 "all / every" = F；原文说 "always" → 题干写 "sometimes" = F。
  • 找不到对应信息直接 NG：读完原文仍无对应段 = NG，不要硬找。
  • 含 all / never 极可能是 F 或 NG：极端词几乎不会是 True。
  • 同义替换识别：题干 significant ↔ 原文 important 是 T；题干 increase ↔ 原文 decrease 是 F。

30 秒动作：在题干里圈一个数字 / 大写专有名词作为定位词 → 回原文扫相同词。

Type 3. Identifying writer's views/claims（Yes / No / Not Given）

题型形式：判断陈述是否符合作者观点/主张；常见于 Passage 3 / Passage 4；题量通常 4–6 题。

  • 关注"观点动词"：believe / argue / claim / suggest / doubt 才是观点；事实描述（in 1990...）不算观点。
  • Yes ≠ True：Yes 是"作者认同"，不是"客观正确"；No 是"作者反对"；NG 是"作者未表态"。
  • 警惕双面表达：some...but... / however / although 后常藏作者真实观点。
  • 区分 claim 与 fact：fact 不论作者是否提到都是事实；claim 必须作者亲口说。
  • 形容词/副词的修饰倾向：unfortunately / remarkably / surprisingly 暗示作者态度。
  • 找不到原话 = NG：作者没明确表达该观点 = NG，不要替作者脑补。

30 秒动作：圈题干里的观点动词（believe / argue / claim） → 回原文找作者本人表达这些动词的句子。

Type 4. Matching information（段落信息匹配）

题型形式：题目描述某信息，问该信息出现在哪一段；常见于 Passage 2；题量通常 4–7 题。

  • 独特信息作锚：人名 / 年代 / 地点 / 数字等独特信息直接对应原文位置。
  • 一题只配一段（除非 NB）：注意题干是否注明"某段可能被选多次"。
  • 划掉已选段落：若 NB 未注明复用，做完一题立刻在原文划掉对应段，避免重复使用。
  • 关键词回归原文：题目关键词 + 原文同义替换双重核对，脑补 = 0 分。
  • 关注题干格式：Which paragraph contains the following information? 是乱序题，不要按题号顺序在原文找。

30 秒动作：把每题题干中独特的人名 / 数字 / 大写词列在题号旁 → 通读时打勾定位。

Type 5. Matching headings（段落标题匹配）

题型形式：从一组标题选项中为每段选一个最佳标题；常见于 Passage 3（必出）；题量 = 段落数。

  • 先读所有 heading 选项：划每个 heading 的核心名词 / 形容词；找出重复词（重复词常是干扰项的关键词）。
  • 段首二句 + 段末一句：段落主旨几乎一定在首二句和末句；中间是论据和例子。
  • 同义替换要能对应：heading 关键词必须在段落主旨句里能找到同义对应；找不到 = 干扰项。
  • 警惕太宽 / 太窄：too general（覆盖全文不止一段）= 错；too specific（只是细节而非主旨）= 错。
  • 留意转折后：however / but / in fact 之后往往是段落的真实主张。
  • 排除明显论据：选项若只是描述一个例子或数字，没有上升到主旨 = 干扰项。

30 秒动作：把所有 heading 关键词扫一遍，标出高频重复词 → 这些词出现在选项里时多半是干扰。

Type 6. Matching features（特征匹配）

题型形式：把一组 features（人名 / 缩写 / 年代 / 理论名）与 statements 配对；常见于 Passage 3；题量 4–6 题。

  • 先扫 feature 列表：把人名 / 缩写 / 术语在原文逐一标出位置，建立"人物地图"。
  • 每个 statement 独立判断：本题是乱序，不能按题号顺序在原文找。
  • 注意 NB 复用：题干可能注明"同一 feature 可被选多次"——此时别划掉已选项。
  • 立场 / 语气不符即排除：某研究者若全文持反对态度，statement 写"suggest positive..."多半不属他。
  • 关注 statement 中的限定词：only / first / most / always 帮你区分各研究者立场。
  • 无 NB 时一 feature 一 statement：选过的立刻划掉。

30 秒动作：扫一遍 feature 列表 → 在原文中用首字母标出每个 feature 的出现位置。

Type 7. Matching sentence endings（句子结尾匹配）

题型形式：左栏句子开头 + 右栏句子结尾，两栏配对；常见于 Passage 2 / 3；题量 5–6 题。

  • 先看后半句：圈右栏每个结尾的动词 / 名词 / 介词短语；再看左栏开头。
  • 主谓一致是底线：单数主语 + 复数谓语 = 直接排除；时态不匹配 = 排除。
  • 上下文逻辑：因果（because...）、转折（however...）、对比（unlike...）逻辑不通 = 排除。
  • 不看原文也能做对：本题是纯语法 + 逻辑题，原文只提供话题背景，不必先读原文。
  • 左栏顺序与原文一致：从左栏第一题开始按顺序在原文中找对应段，定位话题范围。
  • 排除留一：通常右栏比左栏多一个，最后剩下那个若仍有两个候选，用逻辑再筛。

30 秒动作：圈右栏每个结尾的核心动词 / 名词 → 配左栏主语单复数和逻辑连接词。

Type 8. Sentence completion（句子填空）

题型形式：补全句子，答案直接来自原文；常见于 Passage 1 / 2；题量 4–6 题；严格字数限制。

  • 严格守字数：NO MORE THAN TWO WORDS 即不能超 2 词；多 1 词 = 0 分。
  • 空前空后定词性：空前 the / a / an = 名词；空后 verb / adjective = 名词；空后 of / in = 名词或动名词。
  • 用空前实词定位：圈空前的实词（专有名词 / 数字 / 动词）→ 回原文找同义替换。
  • 单复数必须一致：原文 studies = 答案 studies，不能写成 study。
  • 不需改写：填空题答案几乎都是原文原词或微调，不需改写时态 / 词性。
  • 拼写严格：写完检查拼写，错 1 字母 = 0 分。

30 秒动作：看空前 1 个实词 + 空后 1 个词 → 预判词性和大致含义 → 回原文同义替换定位。

Type 9. Summary / note / table / flow-chart completion（摘要填空）

题型形式：填空大类，答案来自原文某段或全文；常见于 Passage 2 / 3；题量 4–6 题。

  • 摘要首句是定位锚：摘要第一句通常点明来源段落 / NB 范围 / 方框引文，是定位关键。
  • 题序 = 原文顺序：填空题普世原则——按题号顺序往下找，不要跳题。
  • 词性 + 字数 + 同义替换三件套：预判词性 + 守字数 + 同义替换是核心动作。
  • flow-chart 顺箭头：流程图按箭头方向 = 顺序，逆箭头必是干扰。
  • table 看行列交叉：table 题答案在行标题和列标题的交叉语义里。
  • "from the list"必选选项：若题干给了选项方框，答案必在框内；不要填框外词。

30 秒动作：读摘要第一句找定位锚（段落号 / NB / 引文） → 圈该段中每个空的同义替换点。

Type 10. Diagram / flow-chart / table completion（图示填空）

题型形式：在图示（流程图 / 示意图 / 表格）上标注位置填词；常见于 Passage 2 流程描述 / Passage 3 实验类。

  • 先看图名 + 已给标签：图的标题常含定位关键词（"the water cycle" → 找 water cycle 段）；已给的标签词就是定位锚。
  • 箭头 / 方框指示顺序：flow-chart 箭头方向 = 阅读顺序；左右结构 / 上下结构指示空间或时间关系。
  • 同图题序 = 原文顺序：同一图内的题按顺序在原文里出现；标完一题立刻在原文划掉对应区间。
  • 填词多有名词性：图示填空常填名词 / 术语；动名词和动词短语较少。
  • 注意"which step / which stage"：若问"哪一步"，看图上编号或流程节点。
  • table 注意列与行的对应关系：跨列填词时，确认是哪一行的属性填到哪一列。

30 秒动作：看图标题 + 已给标签 → 在原文中定位对应段（标题里的关键词是锚）。

Type 11. Short-answer questions（简答）

题型形式：问句 + 简短回答（常 NO MORE THAN THREE WORDS）；常见于 Passage 1；题量 4–6 题。

  • 用疑问词定词性：when → 时间；where → 地点；why → 原因；how → 方式；what → 名词。
  • 严格守字数：常 NO MORE THAN THREE WORDS；多 1 词 = 0 分。
  • 答案直接来自原文：简答题几乎不需改写，原文原词或微调即可。
  • 题序 = 原文顺序：按题号顺序往下找。
  • 拼写 + 单复数严格：错字母 / 错单复数 = 0 分；写完检查。
  • 大小写不评分：专有名词大小写不影响判分（以官方为准），但拼写必须对。

30 秒动作：圈问句的疑问词 → 决定要填什么（时间 / 地点 / 名词） → 回原文按顺序定位。

5 条黄金策略

贯穿 11 个题型的 5 条最高优先级策略 —— 每条都是得分底线。

  1. 顺序原则：同一题型内，题号顺序 = 原文出现顺序（Heading、Matching features、Matching information、Matching sentence endings 除外——这 4 类是乱序题）。填空题、判断题、单选题几乎全是顺序题。
  2. 同义替换：答案词 / 观点在原文中几乎从不被原词重复，训练"识别意思不识别字面"。高频同义替换对：important ↔ significant ↔ crucial；increase ↔ rise ↔ grow；cause ↔ lead to ↔ result in。
  3. 定位优先：先看题后读文。划题干中的硬词（数字 / 大写 / 人名 / 年代）作为定位锚 → 回原文扫相同词 → 找同义替换 → 答案落点几乎都在定位句的下一句或同义替换最密集处。
  4. 时间分配：60 分钟 / 3 篇 ≈ 20 分钟 / Passage。先做 P1（最简单），再做 P2，最后 P3；每篇超时立即跳下一篇，回头再补。
  5. 跳过难题：单题超过 2 分钟无思路 → 立刻标记跳过，先把所有会的做完，最后回头做标记题。放弃 = 必失分；跳过后回头做 = 50% 拿分。
