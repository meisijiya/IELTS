# 官方四项评分标准详解（Task 1 / Task 2，2026 版）

> 数据来源：British Council / IDP 官方公开版（IELTS Writing Band Descriptors, Public Version）+ Cambridge Assessment English + 2024–2025 年考务更新。

## 评分框架

四项标准各占 25%，每项独立 0–9 分（可半档）。

```
Task 分 = (TA + CC + LR + GRA) / 4   （单 Task）

总 Writing 分 = (Task 1 平均 + Task 2 平均 × 2) / 3
```

**.25 规则**：.25 → 进位到上半档；.75 → 进位到下一整数档。

## 一、Task Achievement (Task 1 Academic) / Task Response (Task 2)

### Task 1 Academic — Task Achievement

| Band | 描述 |
|---|---|
| **9** | 完全满足任务要求，呈现完整展开的回应。 |
| **8** | 充分覆盖所有要求；清晰呈现并图示关键特征 / 要点。 |
| **7** | 覆盖任务要求；清晰呈现主要趋势 / 差异 / 阶段总览；呈现关键特征但不充分展开。 |
| **6** | 回应任务要求；总览存在但选材可更恰当；呈现关键特征但细节可能不相关 / 不准确。 |
| **5** | 一般性回应任务；格式偶有不合适；机械复述细节、无清晰总览；呈现关键特征但覆盖不足。 |
| **4** | 试图回应任务但未能覆盖所有要点；信息格式不恰当；细节不相关 / 不准确 / 不足。 |
| **3–0** | 未达到任务要求；信息无条理或与任务无关。 |

### Task 1 GT — Task Achievement

| Band | 描述 |
|---|---|
| **9** | 完全满足任务要求；语气始终得体；清晰呈现并图示关键要点。 |
| **8** | 充分覆盖所有要求；语气得体一致；清晰呈现关键要点。 |
| **7** | 覆盖任务要求；语气一致；呈现关键要点但偶有不充分展开。 |
| **6** | 回应任务要求；语气基本一致；要点齐全但偶有不相关 / 不准确。 |
| **5** | 一般性回应；语气偶有不一致；要点部分覆盖但不够充分。 |
| **4** | 试图回应任务但格式 / 语气不一致；要点部分覆盖。 |

### Task 2 — Task Response

| Band | 描述 |
|---|---|
| **9** | 完全回应任务所有部分；全程贯穿明确立场，并充分展开；无无关内容。 |
| **8** | 充分回应所有部分；立场清晰、有支撑；偶有轻微不相关内容或推理略欠展开。 |
| **7** | 回应所有部分但覆盖程度不一；立场清晰但结论或理由偶有未充分展开。 |
| **6** | 回应任务但主要观点可能不清晰、重复或不完全相关；立场可能不清晰 / 不一致。 |
| **5** | 部分回应任务；可能偏题；观点有限、展开不充分；细节可能不相关。 |
| **4** | 试图回应任务但立场不清晰；观点重复 / 不相关；展开不足。 |

### TA/TR 关键扣分点

- **字数**：Task 1 < 150 / Task 2 < 250 必扣；每少 10 词扣 1 分（在 TA 中体现）。
- **Overview 缺失**：Task 1 Academic 必须有"无数据的趋势概述段"，否则 TA 卡 6。
- **立场模糊**：Task 2 全程未明示自己的观点，TR 卡 6。
- **回应不完整**：Two-part Question 只答一问必扣。
- **GT 书信**：未达成写信目的（投诉无诉求 / 求职无亮点），TA 卡 5。

## 二、Coherence & Cohesion (CC)

| Band | 描述 |
|---|---|
| **9** | 衔接使用不引起注意；段落安排完美服务于论点。 |
| **8** | 信息与观点逻辑排列；全面管理衔接；段落使用恰当。 |
| **7** | 逻辑组织信息与观点；全程有清晰推进；多样衔接恰当使用但偶有过度 / 不足。 |
| **6** | 信息排列连贯，有整体推进；衔接有效但句内 / 句间欠连贯或机械；指代可能不清晰。 |
| **5** | 信息组织但整体推进不足；衔接不准确 / 过度使用；缺乏指代造成重复。 |
| **4** | 无法提供清晰组织；衔接极少；分点杂乱。 |
| **3–0** | 无连贯组织；几乎无衔接。 |

### CC 关键扣分点

- **每段开头都是 "Firstly / Secondly / Moreover"**：机械衔接。
- **段落内有两个不相关论点**：段落主题不清。
- **代词指代不清**："this" / "these" 指代不明。
- **段落数 = 句子数 = 1 段=1 段**：每段都应有 2+ 句。
- **GT 书信不分段**：信内所有内容堆一段，CC 直接卡 5。

### CC 6 → 7 升档关键

- 每段一个明确主题句（Topic Sentence）。
- 用代词 / 指示词 / 同义词链避免重复。
- 替换机械 "firstly / moreover" 为更自然的衔接。

## 三、Lexical Resource (LR)

| Band | 描述 |
|---|---|
| **9** | 词汇范围广，词汇特征自然、精细控制；极少轻微错误。 |
| **8** | 词汇范围广、流畅灵活传达精确含义；熟练使用不常见词汇但偶有不准确；拼写 / 词形错误极少。 |
| **7** | 词汇范围足够灵活精准；使用不常见词汇有风格 / 搭配意识；词选 / 拼写 / 词形偶有错误。 |
| **6** | 词汇范围对任务足够；尝试使用不常见词汇但有不准确；词形 / 拼写错误但不阻碍沟通。 |
| **5** | 词汇范围有限但最低够用；拼写 / 词形错误明显，可能给读者造成困难。 |
| **4** | 词汇范围有限；错误频繁；有时阻碍沟通。 |
| **3–0** | 词汇极少；基本无法沟通。 |

### LR 关键扣分点

- **错误搭配**："do a decision"、"economical growth" → 必扣分。
- **不规范缩写 / 口语**："wanna"、"gonna" → 0 分（GT 书信非正式信中可少量使用 contractions，但不接受 slang）。
- **拼写错误反复**：同一词反复错，标记为"系统性错误"。
- **重复用词**：同一名词 / 动词反复出现而不替换。
- **GT 书信语气错配**：在正式信中用 slang（"gonna"、"stuff"）→ LR 卡 5。

### LR 6 → 7 升档关键

- 学**搭配**（collocations）而非单词："make a decision"、"pose a threat"、"raise awareness"。
- 用同义词避免重复，但要"准确" > "花哨"。
- 写作时检查是否有一个错词反复出现。

## 四、Grammatical Range & Accuracy (GRA)

| Band | 描述 |
|---|---|
| **9** | 结构范围广，完全灵活准确；极少轻微错误。 |
| **8** | 结构范围广；多数句子无错误；极少错误或不恰当。 |
| **7** | 多种复杂结构；频繁无错句；语法与标点控制良好但偶有错误。 |
| **6** | 简单与复杂句混合；语法与标点错误但罕见阻碍沟通。 |
| **5** | 结构范围有限；尝试复杂句但较简单句更不准确；语法错误频繁。 |
| **4** | 极少结构；主谓一致 / 时态错误频繁；少于 50 词。 |
| **3–0** | 基本无语法结构；难以识别。 |

### GRA 关键扣分点

- **残句（Sentence Fragment）**："A followed very closely by B。" → 分词无主句，直接扣到 5.5。
- **主谓不一致**：单复数错误。
- **时态错误**：动态图描述在过去时态，概述段在现在时态。
- **冠词错误**："take a action"、"important role in the society"。
- **介词错误**：高频但易错。
- **GT 书信语气语法错配**：正式信中用 contractions（I'm / don't）太多 → GRA 略扣。

### GRA 6 → 7 升档关键

- **每段至少 1 个定语从句 / 条件句 / 被动语态**。
- **避免残句**：先主谓后右扩，复杂结构（定语 / 同位语 / 分词 / 介词短语）全放句末。
- **每句 2–3 组信息**：超过 3 组 → 切分。
- **优先准确而非复杂**：4 句复杂句对 2 错 1 算 6.5，4 句全对才算 7。

## 七、2026 年评分微调要点

1. **错误容忍度更严**：5–6 分段作文中"系统重复错误"会被明确标记为 TA / LR 扣分项；过去宽松处理的小错误现在计入"系统性错误"。
2. **Task 2 反方观点处理更受重视**：Discuss Both Views 题型如果只写一方观点 + 一句话带过另一方，TR 评估时会明确扣分。
3. **同义替换与原创性**：直接套用模板套话（"It is undeniable that..."、"With the development of society..."）被视为 TA / CC 双扣分项，2024 年起多次出现在考官反馈中。
4. **GT 书信目的清晰度**：投诉信 / 建议信中若主体段没明确"我希望如何解决"，TA 卡 6。
