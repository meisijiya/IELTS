# 中国学生「中式英语」搭配清单（从 5.5 卡到 7+ 的最后一公里）

> 数据来源：IDP 中国学生常见问题文章、British Council 官方 Pronunciation 文章、IELTS Liz / E2 IELTS 中国学生专章、Cambridge Linguaskill 中国考生分析报告。
>
> **核心立场**（必须在第一节讲清楚）：
> "中式英语能不能拿高分？" — 分两种：
> 1. **硬伤型中式英语**（让考官听不懂或觉得"不准确"）→ **必改，否则封顶 5.5**。
> 2. **风格型中式英语**（能听懂，但"味道"像翻译）→ 6.5 分可容忍；7+ 才开始扣分。
>
> 本文件按"必改的 → 可容忍的 → 加分项"三段拆开。**先消灭必改的，再处理可容忍的**。
>
> ⚠️ **使用范围说明**：本文件中"卡 5.5/6"等扣分阈值、错误频次 vs 估分表为**教学经验启发**（来自多个考生案例 + 资深讲师观察），**非官方评分细则**。官方按整体描述匹配评分，不是按错误次数机械扣分。

## 第一节 必改的 20 个硬伤（不改正 ≤ 5.5）

### 类别 1：动词-宾语搭配（collocation 错位）

中文里动词+宾语是按字面意思拼的，英文必须按"惯用搭配"用。

| 错 | 正 | 解释 |
|---|---|---|
| **learn knowledge** | **acquire / gain knowledge** / **learn a lot** | 英文里 learn 不直接接 knowledge |
| **open the light / open TV** | **turn on the light / TV** | "打开电器"用 turn on；"打开门"用 open the door |
| **close the light / close TV** | **turn off the light / TV** | 同上，关电器 |
| **eat medicine** | **take medicine** | 吃药 = take medicine（"吃"在英文里大多用 take） |
| **eat soup** | **have soup** | 喝汤 = have soup / eat soup 都行，但 have 更地道 |
| **drink soup** | **eat soup** / **have soup** | 喝 vs eat 区分：drink 用于饮品，eat 用于汤/麦片 |
| **touch phone number** | **give / share your phone number** | "留下"号码用 give / share |
| **receive phone call** | **receive a call / get a call** | "接到电话" |
| **return money back** | **return the money** / **give the money back** | return 自带"回"，不要 back |
| **discuss about the topic** | **discuss the topic** | discuss 不接 about |
| **enter into the room** | **enter the room** / **go into the room** | enter 不接 into |
| **reach to** | **reach** | reach 本身是及物动词 |
| **emphasize on** | **emphasize** | emphasize 也不接 on |
| **contact with him** | **contact him** | contact 是及物动词 |
| **concentrate on** | ✓ 这个对！ | 不用改 |
| **listen to music** | ✓ 这个对！ | 不用改 |
| **look at the picture** | ✓ 这个对！ | 不用改 |
| **wait for the bus** | ✓ 这个对！ | 不用改 |

### 类别 2：形容词-介词搭配

| 错 | 正 | 解释 |
|---|---|---|
| **good in English** | **good at English** | good at 形容技能 |
| **interested for music** | **interested in music** | interested in |
| **married with** | **married to** | 嫁/娶给某人 |
| **angry with / at** | ✓ 两个都对！ | 看你想表达"对人"还是"对事" |
| **similar with** | **similar to** | similar to |
| **different from** | ✓ 这个对！ | 不用改 |
| **afraid of** | ✓ 这个对！ | 不用改 |
| **proud of** | ✓ 这个对！ | 不用改 |
| **tired of / from** | ✓ 都对！ | of = 长期厌倦；from = 单次疲劳 |
| **famous with** | **famous for** | 著名因某事 |
| **full with** | **full of** | full of |
| **crowded with** | ✓ 这个对！ | 不用改 |

### 类别 3：动词时态 / 主谓一致（语法硬伤）

| 错 | 正 | 解释 |
|---|---|---|
| **he don't / she don't** | **he doesn't / she doesn't** | 第三人称单数现在时 |
| **he go / she like** | **he goes / she likes** | 同上 |
| **I am go / I am like** | **I go / I like** | 现在时不用 be + verb |
| **although... but...** | **Although..., ...** / **..., but...** | although 和 but 不能同句出现 |
| **because... so...** | **Because..., ...** / **..., so...** | because 和 so 不能同句出现 |
| **I very like it** | **I really like it** / **I'm really into it** | very 不能修饰动词 |
| **I very busy** | **I'm very busy** | 形容词前必须有 be |
| **yesterday I go** | **yesterday I went** | 过去时 |
| **since 3 years** | **for 3 years** / **since 3 years ago** | since + 时间点；for + 时间段 |

### 类别 4：冠词 / 量词 / 不可数名词

| 错 | 正 | 解释 |
|---|---|---|
| **a advice / an advice** | **a piece of advice / some advice** | advice 不可数 |
| **a information / informations** | **some information / a piece of information** | information 不可数 |
| **a furniture / furnitures** | **a piece of furniture / some furniture** | furniture 不可数 |
| **equipments** | **equipment** | 单复同形 |
| **homeworks** | **homework** | 单复同形 |
| **a news** | **a piece of news** | news 不可数 |
| **the society / the government**（泛指时） | **society / the government** | "社会"作为抽象概念时无 the |
| **in the society** | **in society** | 同上 |
| **play a football** | **play football** | 球类运动无冠词 |

### 类别 5：高频中式句式

| 错 | 正 | 解释 |
|---|---|---|
| **give you some colors see see** | **(绝不写)** | 这是字面翻译，英文不存在 |
| **you see see** | **take a look** | "看一下"用 take a look |
| **how to say...** | **how do you say...** / **how to pronounce...** | how to say 是死记硬背的痕迹 |
| **my English is poor** | **my English isn't very strong** / **I'm not very fluent in English** | 直接说 "is poor" 让 LR 跌 1 档 |
| **I have no idea** | ✓ 这个对！ | 不用改，但别说 "I have no idea + 中文" |
| **people mountain people sea** | **there were crowds of people / it was packed** | 形容人多 |
| **do you have free time?** | **are you free?** / **do you have time?** | "有空吗" |
| **the reason is because...** | **the reason is that...** | 重复：reason ≠ because |
| **the problem is the traffic is very big** | **the problem is that there's a lot of traffic** | 中文"交通很大"直译 |
| **we are living in the 21st century** | ✓ 这个对！ | 不用改 |

## 第二节 可容忍的 10 个「风格型」中式英语（6.5 没事，7+ 才修）

> 这些**不算错误**，但会让你听起来像"翻译过来的"。修掉就从 6.5 → 7。

| 中式 | 更地道的英文 |
|---|---|
| **very / really + 任何形容词** | truly / genuinely / absolutely / incredibly + 关键形容词（如 truly inspiring / genuinely fascinating） |
| **I think / I think... 很频繁** | from my perspective / it seems to me / if I had to say / my take on this |
| **because...**（每句都用） | The main reason is that / This is largely because / What drives this is |
| **and... and...**（一直并列） | on top of that / another thing is / what also stands out is |
| **happy**（高频） | thrilled / over the moon / pretty chuffed / couldn't be happier |
| **very good / very bad** | fantastic / terrible / awful / brilliant / dreadful |
| **very important** | crucial / vital / of great importance |
| **many people think...** | a lot of people believe / there's a widespread belief that / it's commonly held that |
| **nowadays** | these days / at present / currently / in recent years |
| **in China**（回答 In my country 时太直白） | where I come from / in my home country / in my part of the world |

## 第三节 加分项：让 7 → 8 的 8 个 idiom / 高级搭配

> 这些**不出现不扣分**；但出现 2–3 个就让考官下意识给高分。

| 表达 | 用途 |
|---|---|
| **a blessing in disguise** | 形容"塞翁失马" |
| **on the fence** | 形容犹豫不决 |
| **the ball is in someone's court** | 形容轮到他做决定 |
| **up in the air** | 形容悬而未决 |
| **by and large** | 总体来说 |
| **to be honest / to be fair** | 表达立场（替代 I think） |
| **the bottom line is** | 总结 |
| **at the end of the day** | 归根到底 |

## 第四节 自查口诀（写完 / 说完后过一遍）

**CAST 检查法**：

1. **C**ollocation — 动词和宾语搭配对吗？（`make a decision`，不是 `do a decision`）
2. **A**rticles — 冠词 / 不可数名词对吗？（`some advice`，不是 `a advice`）
3. **S**ubject-verb agreement — 主谓一致吗？（`he goes`，不是 `he go`）
4. **T**ense — 时态对吗？（`yesterday I went`，不是 `yesterday I go`）

**10 秒过一遍**这 4 项，能抓出 80% 的中式英语错误。

## 第七节 "中式英语也能拿高分" 的 3 个真实场景

> 用户原话："中式英语都能拿高分那最好了。"
>
> 诚实的回答：**不能"全中式"还能拿 7+**，但**少量中式英语完全不影响 6.5**。
>
> 以下 3 个真实场景：

### 场景 1：偶尔的 "very like"（不致命）

如果 11 分钟里出现 1 次 `I very like this book`，其它表达都是 7 分水准——LR 仍可拿 7。考官按"整体语言水平"评分，不是"逐句扣分"。

### 场景 2：发音带中国口音（不致命）

中国学生有口音完全不影响拿 8 分——只要 stress-timing 和 individual sounds 都做对，口音只是"风格"。

### 场景 3：把 "中式英语" 当借口——这是错的

> ⚠️ 真正的高分不是"中式英语能拿高分"，而是"中式英语不是错误"。
>
> 例 1：`I have no idea` ✓ 正确（不算中式英语）
> 例 2：`I haven't thought about it before, but my instinct would be...` ✓ 正确
> 例 3：`I don't know` ✓ 正确
> 例 4：`我不知道`（直接英译）❌ 中式英语

**结论**：戒掉"中式英语 = 表达不地道"的执念。**真的英文很简单，直接说就行**。

## 第九节 把中式英语变成"地道表达"的练习模板

### 模板：错 → 对 → 解释 → 例句

```
错：I very like this book.
对：I'm really into this book. / I absolutely love this book.
解释：very 不能修饰动词 like；用 really into / absolutely love 替换。
例句：I'm really into this book — I've read it three times already.
```

把这个模板套到第一节每个错误上，每天练 5 条，2 周能消灭 80% 的中式英语。

## 第十节 在 SOP-B 生成答案时的应用规则

> 本文件是**生成模式（SOP-B）必须检查**的硬性清单。

1. **生成任何 Part 1/2/3 答案前**，必须先扫一遍"必改的 20 个硬伤"——确认范例中**没有这些错误**。
2. **生成后必须用 CAST 检查法**（第四节）过一遍。
3. **如果目标分数 ≥ 7**，必须额外用"可容忍 10 个"清单过一遍，把"很 very / think"替换为更地道的表达。
4. **如果目标分数 ≥ 7.5**，可以加入第三节的加分 idiom 1–2 个。
5. **如果目标分数 < 6.5**，可以保留少量"风格型中式英语"——保留真实感，避免过度润色显得像 AI 写的。
