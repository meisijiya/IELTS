# 雅思口语应试工具包（Speaking Toolkit）

> **用途**：考试前集中背诵 / 平时滚动复习 / Agent 教学时按需调用。
> **整合源**：本地 skill 现有内容（part1-guide / part2-guide / part3-guide / chinese-english-pitfalls / band-descriptors）+ 课程新增内容（万能句型、Create a Window、双元音等）。
> **使用原则**：**少而精 > 多而杂**——选 3–5 个你用得顺的背熟，比背 30 个但说不出口强 10 倍。

---

## 第一部分：填充词（Fillers）

> **为什么重要**：流利度的关键不是"说得快"，而是"卡顿时有东西垫"。官方 Band 6 的 *"coherence may be lost ... as a result of hesitation"* 翻译成大白话就是：**死寂 2 秒 = 失分**。填充词 = 把"死寂"变成"思考间隙"。
>
> **使用规则**：
> 1. **句中用**：well / I mean / actually / you know / the thing is
> 2. **句首用**：To be honest / Actually / I guess / Believe it or not
> 3. **句尾用**：you know what I'm saying / kind of / I guess
> 4. **不要用**：um / ah / 那个 / how to say（中式停顿的标志）

### 1.1 开口型（开始答第一句时）

| 填充词 | 用法 | 例句 |
|---|---|---|
| **Actually,** | 最万能的句首 | Actually, I live in Shenzhen. |
| **To be honest,** | 表"坦诚"，适合评价题 | To be honest, I don't really like cooking that much. |
| **Well,** | 经典犹豫型开头 | Well, it depends on the situation. |
| **I guess,** | 表达"个人估计" | I guess I'd say morning is better. |
| **Believe it or not,** | 强调"奇遇感" | Believe it or not, I've never been to Beijing. |
| **You know,** | 引出"共识"或转折 | You know, I think this is pretty common in China. |

### 1.2 思考型（卡顿时救命）

| 填充词 | 用法 | 例句 |
|---|---|---|
| **I mean,** | 重述 / 自我修正 | I mean, what I'm trying to say is... |
| **The thing is,** | 引出"真正的问题" | The thing is, I don't have much time on weekdays. |
| **Let me think...** | 显式"我要想一下" | Let me think... yes, that was about three years ago. |
| **It's hard to say, but...** | 引出犹豫结论 | It's hard to say, but I think... |

### 1.3 句尾型（让句子自然收束）

| 填充词 | 用法 | 例句 |
|---|---|---|
| **...you know what I'm saying** | **只能放句尾**，表示"你懂我意思吧" | Shenzhen is really convenient, subway everywhere, you know what I'm saying. |
| **...kind of** | 缓和语气 | I kind of like it, but not that much. |
| **...I guess** | 软化立场 | It's fine, I guess. |
| **...or something like that** | 列举收束 | ...like Subway, KFC, or something like that. |

### 1.4 ❌ 中国学生最常用的错误填充

| ❌ 错误 | ✓ 替换 | 原因 |
|---|---|---|
| um / ah / 呃 | well / I mean | 中式停顿的标志 |
| 那个 / 那个什么 | the thing is / you know | 考试不能讲中文 |
| how to say... | let me think... | "how to say" 是背稿痕迹 |
| 呃...（沉默 2 秒） | Actually, ... / Well, ... | 死寂 2 秒 = 直接失分 |

## 第二部分：常用短语（Common Phrases）

> **分类标准**：按"在哪个 Part 用"+"起什么作用"分类，比按字母背更实战。

### 2.1 万能句型（任何话题都能套）——**课程核心**

```
X is one of the most + 形容词 + 复数名词 + I have ever + 过去分词.
```

**为什么必背**：一个句型套 50 个话题。考官听到这种结构 + 高级形容词 + 完成时 = 直接认定你词汇和语法都到 7 分档。

| 话题 | 范例 |
|---|---|
| 城市 | Shenzhen is one of the most convenient cities I have ever lived in. |
| 食物 | The rice noodles cooked by my mom **are** one of the most mouth-watering breakfasts I have ever eaten. |
| 职业 | Working as an English teacher is one of the most meaningful jobs I have ever done. |
| 歌手 | Jay Chou is one of the most popular Chinese singers I have ever heard of. |
| 运动员 | LeBron James is one of the greatest basketball players I've ever seen. |
| 歌曲 | 手写的从前 is one of the most popular songs by Jay Chou I have ever listened to. |

**⚠️ 易错点**：
- `greatest` 已经是最高级，**不能再加 `most`**（错：the most greatest）
- **最高级规则**：短音节形容词（great → greatest / big → biggest / tall → tallest）加 `-est`；**多音节形容词**（important → most important / beautiful → most beautiful / convenient → most convenient）用 `most + 原形`
- `singer` 的发音：/ˈsɪŋə/（英式） /ˈsɪŋɚ/（美式），不是 /ˈsɪndʒə/（错把 ng 念成 ndʒ）
- 说具体（iPhone）而不是笼统（phone），越具体越像 7 分

---

### 2.2 Create a Window（解释触发词）——**课程核心**

> **原理**：回答时主动埋入"可扩展"的钩子词，给"展开解释"留出接口。
> **核心问题**：中国学生最常犯的错误是"只给信息不解释"——考官听到 30 秒没听到 because/so/why，分数立刻掉。

**5 个核心触发词**：

| 触发词 | 用法 | 范例 |
|---|---|---|
| **because** | 最直接的因果 | I live in Futian because my parents work there. |
| **so** | 接结果 | ...so they bought the apartment in Futian. |
| **the reason is that...** | 正式表达原因 | The reason is that I want to be close to my office. |
| **which is why...** | 高级因果（接从句） | The area is well connected, which is why I chose it. |
| **so that / in order to** | 表目的 | I chose this place so that I could commute easily. |

**对比：没埋钩子 vs 埋钩子**

❌ 没钩子（5.5 答案）：
> I live in Futian. It's a nice place.

✅ 埋钩子（7 分答案）：
> I live in Futian because my parents work there, so they bought the apartment in Futian. The reason I like it is that everything is nearby — my office, the subway, even the gym. It's basically designed for convenience, which is why I never want to move.

---

### 2.3 Part 1 短答短语（每题 15–25 秒）

| 场景 | 短语 |
|---|---|
| 直接回答 | Yeah, I do, actually. / Not really, to be honest. / Well, it depends. |
| 解释原因 | The thing is, ... / I guess it's because... / Apparently, ... |
| 举例 | Like, for example, ... / I remember once, ... / A typical case is... |
| 承认不知道 | I'm not sure exactly, but... / I haven't really thought about it. |
| 部分同意 | Well, kind of, but... / Up to a point, yeah. |
| 结束 | So yeah, that's pretty much it. / Anyway, that's it. |

---

### 2.4 Part 2 过渡词（2 分钟陈述的骨架）

| 阶段 | 短语 |
|---|---|
| 开场 | I'm going to talk about... / I'd like to describe... |
| 第一点 | First of all, ... / To start with, ... / I'd like to begin with... |
| 第二点 | As for [topic], ... / Another thing I remember is... |
| 第三点 | What I also want to mention is... |
| 解释 why | The reason this matters to me is... / Looking back, I think... |
| 收尾 | So that's why... / All in all, ... |

---

### 2.5 Part 3 抽象化与 Hedging 短语

| 场景 | 短语 |
|---|---|
| 从个人到大 | In my country, most people believe that... / Generally speaking, ... / From a broader perspective, ... |
| 表达立场 | From my perspective, ... / It seems to me that... / If you ask me, ... |
| 推测 | It's possible that... / I imagine we'll see... / One could argue that... |
| 让步 | On the other hand, ... / Having said that, ... / Admittedly, ... |
| 概括 | On balance, ... / All in all, ... / Broadly speaking, ... |

> ⚠️ **Hedging ≠ 没立场**：用 hedging 是为了"软化"语气，不是为了"模糊"立场。必须有一个明确结论。

---

### 2.6 自我修正（让考官觉得你"有意识"）

| 情境 | 短语 |
|---|---|
| 换词 | I mean, ... / ...or rather, ... / sorry, let me rephrase that. |
| 改时态 | actually, no, I should say "went" not "go" — |
| 改主意 | sorry, that's not quite right. What I mean is... |

## 第三部分：常用词（Common Words）

> **背诵原则**：**替换 ≠ 堆砌**。每个高频词背 1 个替换词 + 1 个错示范，比背 5 个替换词但用错强。
> **使用规则**：考试不要"炫词汇"——考官要的是"用得对"而不是"用得难"。

### 3.1 描述感受（替换 happy / good / delicious）

| � 基础词 | ✓ 替换词 | 区分（什么时候用） |
|---|---|---|
| delicious | **mouth-watering** | 食物好吃得流口水，最具体 |
| good（食物） | **satisfying** / **filling** / **hearty** | 吃完感觉满足 |
| good（泛用） | **fabulous** / **brilliant** / **fantastic** | 描述好体验 |
| happy | **thrilled** | 强调激动感（心跳加速） |
| happy | **over the moon** | 强调非常开心 |
| happy | **pretty chuffed** | 英式英语，"挺得意" |
| happy | **couldn't be happier** | 强调"不能再开心了" |
| sad | **gutted** / **devastated** | 强调被打击 |

**Satisfy vs Thrilled 区分**（课程强调）：
- **Satisfy**：你拥有你需要的一切，所以感到满足（更平静）
- **Thrilled**：像坐过山车时那种激动、心跳加速（更强烈）

---

### 3.2 描述程度（替换 very / really）

| ❌ 基础 | ✓ 替换 | 用法 |
|---|---|---|
| very good | **absolutely fantastic** | 强调程度 |
| very interesting | **genuinely fascinating** | 强调"真的" |
| very important | **incredibly significant** | 强调重要性 |
| very fast | **remarkably quick** | 强调速度 |

> ⚠️ **`very` 不是不能修饰形容词**（very good 是对的），但用得多 = 词汇单调。每段最多 1 个 `very`。

---

### 3.3 描述频率（替换 always / often）

| ❌ 基础 | ✓ 替换 | 用法 |
|---|---|---|
| always | **constantly** / **all the time** | 频率 100% |
| often | **frequently** / **regularly** | 高频 |
| sometimes | **occasionally** / **from time to time** | 中频 |
| never | **rarely** / **hardly ever** | 低频 |

---

### 3.4 描述评价（替换 important / good / bad）

| ❌ 基础 | ✓ 替换 |
|---|---|
| important | **essential** / **crucial** / **vital** / **of great significance** |
| good（评价） | **beneficial** / **favourable** / **positive** |
| bad（评价） | **harmful** / **detrimental** / **unfavourable** / **negative** |
| helpful | **invaluable** / **indispensable** |

---

### 3.5 描述趋势（替换 more and more / 越来越...）

| ❌ 基础 | ✓ 替换 |
|---|---|
| more and more people | **an increasing number of people** / **a growing number of** |
| 越来越... | **increasingly** / **gradually** / **rapidly** / **steadily** |

---

### 3.6 描述人物（替换 very kind / nice）

| ❌ 基础 | ✓ 替换 |
|---|---|
| very kind | **compassionate** / **considerate** / **thoughtful** |
| very nice | **genuinely warm-hearted** |
| very funny | **hilarious** / **witty** |
| very smart | **brilliant** / **sharp-minded** / **insightful** |

### 3.7 描述地点（替换 beautiful / big）

| ❌ 基础 | ✓ 替换 |
|---|---|
| very big | **vast** / **spacious** / **immense** |

## 第四部分：考试前 30 分钟速查清单

> **用法**：进考场前看一遍这页，每项确认能用。

### 4.1 必须带进考场的"3 个万能句型"

- [ ] **万能句型**：X is one of the most + 形容词 + 复数名词 + I have ever + 过去分词.
- [ ] **解释触发**：because / the reason is that / which is why
- [ ] **过渡句首**：Actually, / To be honest, / Well, / I guess,

### 4.2 必须背熟的"5 个替换词"

- [ ] delicious → **mouth-watering**
- [ ] happy → **thrilled**
- [ ] important → **essential** / **crucial**
- [ ] very + adj → **absolutely / genuinely / incredibly**
- [ ] many people → **a growing number of people**

### 4.3 必须会的"5 个 Part 3 抽象短语"

- [ ] **Generally speaking**, ...
- [ ] **In my country**, most people believe that...
- [ ] **From a broader perspective**, ...
- [ ] **It's commonly held that**...
- [ ] **Having said that**, ... （让步）

### 4.4 必须避开的"3 个中式陷阱"

- [ ] ❌ `learn knowledge` → ✓ **acquire / gain knowledge**
- [ ] ❌ `very + 动词` → ✓ **really + 动词** / **absolutely + love / enjoy**
- [ ] ❌ `the reason is because` → ✓ **the reason is that** / **because**
