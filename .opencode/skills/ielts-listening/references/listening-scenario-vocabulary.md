## 一、S1-S2 场景词汇（9 大高频场景）

### 场景 1：住宿 Accommodation（⭐⭐⭐⭐⭐ S1 最高频）

**核心词汇**：

| 类别 | 词汇 |
|---|---|
| **房型** | single room, double room, twin room, studio, shared flat, dormitory |
| **设施** | kitchen, bathroom, balcony, garage, garden, central heating |
| **家具** | bed, wardrobe, desk, chair, sofa, shelf, lamp, curtain, carpet |
| **电器** | fridge, washing machine, microwave, oven, dishwasher, air-conditioner |
| **费用** | rent, deposit, utility bills, monthly fee, inclusive of bills |
| **合同** | lease, contract, landlord, tenant, notice period, reference |

**听力示例**：
> "The single room is £120 per week, **inclusive of** heating and water. **Deposit** is £200."
> 答案填：single room / £120 / inclusive / £200

## 三、学术词汇词根速查（S4 必背）

学术词汇虽然专业，但 60% 可以通过词根理解。S4 考试**不必全懂，听懂意思就行**。

| 词根 | 含义 | 例词 |
|---|---|---|
| **-ology** | 学问 | biology, ecology, psychology, archaeology |
| **-graphy** | 记录 | photography, biography, geography |
| **-ism** | 主义 | mechanism, organism, tourism |
| **-tion** | 名词后缀 | conservation, exploration, investigation |
| **-ment** | 名词后缀 | development, environment, movement |
| **-ance/-ence** | 名词后缀 | importance, difference, evidence |
| **pre-** | 前 | prehistoric, prediction, preparation |
| **post-** | 后 | postwar, postgraduate, postpone |
| **inter-** | 之间 | international, intercultural, interdependent |
| **multi-** | 多 | multicultural, multimedia, multiple |
| **sub-** | 下 | submarine, subtitle, suburb |
| **super-** | 上 | supernatural, supermarket, supervisor |
| **bio-** | 生物 | biology, biodiversity, biodegradable |
| **eco-** | 生态 | ecology, ecosystem, eco-friendly |
| **-able** | 形容词 | sustainable, renewable, affordable |
| **-al** | 形容词 | environmental, traditional, cultural |

**应用**：S4 听到陌生词时，先拆词根猜意思，再听上下文验证。

## 四、训练方法

### 方法 1：场景词卡片

把每个场景的词汇做成 Anki 闪卡，**正面写中文，背面写英文 + 拼写**。每天 1 个场景（30 词），3 天一轮。

### 方法 2：S4 学术话题集中训练

按 6 大话题分类整理 IELTS 19-21 的所有 S4 音频，按话题分组训练（环境 5 篇、心理 3 篇、历史 3 篇、科技 4 篇）。

### 方法 3：听写测试

用 `scripts/vocab_quiz.py` 每天做 20 词听写测试。错的词标红，2 天后重测。

### 方法 4：场景音频浸泡

每个场景找 2-3 个雅思真题 S1/S2 音频（IELTS 21/20 推荐），边听边标场景词。3 个月后场景词会内化为反应本能。

## 六、立刻可做的 3 个动作

1. **打印本文件"9 大场景词 + 6 大 S4 话题词"**，剪成卡片，每天背诵 30 词（20 分钟）
2. **打开 IELTS 21 任意 Test S4**，识别属于哪个话题，**集中复习该话题词汇**（30 分钟）
3. **运行 `python3 scripts/vocab_quiz.py --all 20`** 做 20 词听写（10 分钟）
