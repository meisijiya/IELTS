# Listening Paraphrase：同义替换 4 大类型 + 高频词族

> 2026 版。同义替换是雅思听力的**核心考点**（填空题答案几乎从不在音频中原词出现，选择题正确答案几乎从不是原文措辞）。本文件给出 4 大类型 + 60 个高频词族 + 否定触发器 + 训练方法。

---

## 一、4 大类型总览

| 类型 | 定义 | 真题示例 |
|---|---|---|
| **1. 词义替换 Lexical** | 用同义词 / 近义词替换 | 题目："expensive" → 音频："costly" |
| **2. 反义替换 Antonym** | 用反义词 + 否定触发 | 题目："common" → 音频："hardly ever seen" |
| **3. 解释替换 Explanation** | 用一句话解释原词 | 题目："furniture" → 音频："tables, chairs and beds" |
| **4. 举例替换 Example** | 用具体例子替代抽象词 | 题目："vehicles" → 音频："cars, buses and trucks" |

**初稿"80%+ 涉及同义替换"判断已修正**：官方无此具体数字，但经验值在 S3/S4 的填空 + 选择题中确实**绝大多数考点涉及替换**。本文件用更严谨表述。

## 二、类型详解

### 类型 1：词义替换 Lexical Substitution

最常见的替换类型。要求**听懂意思不听话面**。

**真题示例**：
> 题目：The museum focuses on ___ history.
> 音频："We are particularly interested in the **industrial** past of this region."
> 答案：**industrial**

**训练方法**：
- 背词族时背**完整词族**而非单个词
- 听到近义词时反应"这是 X 的同义"
- S3/S4 训练重点

### 类型 2：反义替换 Antonym Substitution

用反义词 + 否定触发（hardly / rarely / never / few / only / seldom / scarcely / barely），答案与音频意思相反。

**真题示例**：
> 题目：The hotel was ___.
> 音频："The hotel was **hardly** impressive."
> 答案：**disappointing** / **unimpressive**（反义）

**关键否定触发器清单**（听到立即标记 ⭐）：

| 类别 | 词 |
|---|---|
| **否定前缀** | un-, in-, im-, ir-, il-, dis-, non-, anti-, mis- |
| **否定动词** | fail, lack, miss, deny, refuse, reject, ignore |
| **半否定词** ⭐ | hardly, scarcely, barely, rarely, seldom, few, little, only |
| **否定形容词** | unlikely, impossible, unaware, doubtful |

**应用**：听到否定/半否定词 → 在题目旁画"×"提醒，答案取反义。

### 类型 3：解释替换 Explanation Substitution

用一句解释替代原词。**最考验理解能力**。

**真题示例**：
> 题目：The company produces ___
> 音频："The firm manufactures **a range of plastic containers**, such as bottles and boxes."
> 答案：**plastic containers**

**训练方法**：
- 听到"such as / like / for example / including" → 前面是抽象，例子才是答案
- 听到"called / known as / referred to as" → 后面是答案

### 类型 4：举例替换 Example Substitution

用具体例子替代抽象概念词。

**真题示例**：
> 题目：The lecturer discussed various ___ in the region.
> 音频："She mentioned **mammals such as dolphins and whales** that inhabit these waters."
> 答案：**mammals**（接受范围含 dolphins, whales）

**训练方法**：
- 听到列举（"such as / like / for example / including"）→ 例子本身不是答案，**例子所属类别才是答案**
- 例：dolphins and whales → 类别是 mammals

## 三、否定前缀与后缀速查（反义替换的关键工具）

| 前缀 | 例子 | 说明 |
|---|---|---|
| **un-** | unhappy, unfair, unusual | 最常见 |
| **in-** | inactive, incomplete, indirect | 形容词居多 |
| **im-** | impossible, immobile, immature | 在 m/p/b 前 |
| **ir-** | irregular, irresponsible, irreversible | 在 r 前 |
| **il-** | illegal, illiterate, illogical | 在 l 前 |
| **dis-** | disagree, disappear, disconnect | 动词居多 |
| **non-** | nonfiction, nonprofit, nonstop | 名词居多 |
| **anti-** | antisocial, antibiotic, antifreeze | 含义反义 |
| **mis-** | misunderstand, misspell, mislead | 含义反义 |
| **-less** | careless, hopeless, useless | 后缀变反义 |

**训练技巧**：词根 + 前缀/后缀 = 批量理解陌生词。雅思听力 S4 必备技能。

## 七、训练方法（让同义替换成为本能）

### 方法 1：词族卡片法

把 60 个高频词族做成 Anki 闪卡，**正面写原词，背面写同义词**。每天 20 词，3 天一轮。

### 方法 2：听到替换立刻标注

做真题时，听到任何近义词 / 反义词 / 解释 / 举例，**立即在题卡上画圈**。复盘时统计每 Section 的替换密度（填空题应在 80%+）。

### 方法 3：替换反应速度测试

用 `scripts/paraphrase_quiz.py` 每天做 10 题同义替换 quiz，限时 30 秒/题。

### 方法 4：真题还原训练

拿 IELTS 21/20 任意 Section 4 音频，听写 10 个填空答案，然后对照原文**标记每个答案的替换类型**（词义/反义/解释/举例）。一周后你会发现答案几乎全是被替换的。

## 八、Band 7+ 同义替换能力对照

| Band | 同义替换能力 |
|---|---|
| **5-5.5** | 听到原词能识别，听到近义词反应不过来 |
| **6-6.5** | 简单近义词能识别，反义替换（如 hardly）反应慢 |
| **7-7.5** | 词义/反义替换稳定识别，解释替换需慢速反应 |
| **7.5-8** | 4 种替换都能识别，词性转换反应快 |
| **8.5+** | 替换已成本能，听同时自动识别考点 |

**训练目标**：从"听到原词写"升级到"听懂意思写"，这是 5.5 → 7 的核心转变。
