# Listening Spelling Rules：拼写规范 + 20 词必背易错清单

> 2026 版。雅思听力评分：**拼写错误 = 0 分**（无任何商量余地）。本文件给出字数限制、大小写、单复数、日期/时间/数字格式 + 20 词必背易错清单（初稿只列 5 词已扩充）。

---

## 一、字数限制（必看 ⭐⭐⭐⭐⭐）

**字数超标 = 直接 0 分**。

### 6 种字数限制类型

| 限制 | 含义 | 例 |
|---|---|---|
| **NO MORE THAN TWO WORDS** | ≤ 2 词 | rent / monthly rent（2 词） |
| **NO MORE THAN THREE WORDS** | ≤ 3 词 | a deposit of 200 pounds / 200 pounds（2 词可接受） |
| **ONE WORD ONLY** | 仅 1 词 | accommodation（1 词） |
| **ONE WORD AND/OR A NUMBER** | 1 词或 1 个数字 | 25（数字）/ twenty-five（词+数字） |
| **NO MORE THAN TWO WORDS AND/OR A NUMBER** | ≤ 2 词或数字 | £30（数字）/ 30 pounds（2 词） |
| **NO MORE THAN TWO WORDS** | ≤ 2 词（最常见） | the local industry（2 词，不算 the） |

### 冠词陷阱 ⭐（最常见错误）

- **a / an / the 都算 1 个词**
- 听到 "a green coat" → 写 **"green coat"**（2 词非 3 词）
- 听到 "the reception" → 写 **"reception"**（1 词非 2 词）

### 数字算词规则

- "100" → 算 1 个词
- "one hundred" → 算 2 个词
- "a hundred" → 算 2 个词（a 算 1 词）
- "25%" → 算 1 个词
- "25 percent" → 算 2 个词

## 二、大小写规则

### 雅思考官对大小写的态度

- 答案**大小写不严判**（除非是缩写、专有名词、月份、星期）
- **保险做法**：专有名词首字母大写，其余全大写

### 必大写的情况

| 类型 | 示例 |
|---|---|
| **人名** | John Smith, Dr Wang |
| **地名** | London, Baker Street, Oxford Road |
| **机构名** | British Museum, BBC, University of Manchester |
| **月份** | January, February |
| **星期** | Monday, Tuesday |
| **国籍** | British, Chinese, Australian |
| **语言** | English, Mandarin |
| **节日** | Christmas, New Year |
| **学位** | PhD, MBA, BSc |
| **品牌** | iPhone, Microsoft |

### 不必大写（但可全大写保险）

- 普通名词（book, library）
- 形容词（good, interesting）
- 动词（study, work）

**最保险做法**：所有答案**全大写**写（填空题数字除外）。但月份、星期、人名、机构名必大写。

## 三、单复数规则 ⭐⭐⭐⭐（机考易失分）

### 听音判断

⚠️ **听到复数读音（-s/-es）必须写复数**！

| 听到 | 写 |
|---|---|
| "appointment" | appointment（不可数） |
| "appointments" | appointments（可数复数） |
| "furniture" | furniture（不可数，无复数） |
| "luggage" | luggage（不可数） |
| "informations" | ❌ 错（information 不可数） |
| "advices" | ❌ 错（advice 不可数） |

### 必背不可数名词清单

| 不可数 | 中文 |
|---|---|
| **accommodation** | 住宿 |
| **furniture** | 家具 |
| **luggage** | 行李 |
| **information** | 信息 |
| **advice** | 建议 |
| **equipment** | 设备 |
| **machinery** | 机械 |
| **research** | 研究 |
| **progress** | 进步 |
| **knowledge** | 知识 |

### 空格上下文判断

- "many ___" → 复数
- "an ___" → 单数
- "the number of ___" → 单数
- "a number of ___" → 复数

## 四、日期 / 时间 / 数字格式

### 日期格式

| 类型 | 写法 | 备注 |
|---|---|---|
| **英式（日/月/年）** | 15/03/2026 / 15 March 2026 | 英国、澳大利亚用 |
| **美式（月/日/年）** | 03/15/2026 / March 15, 2026 | 美国用 |
| **雅思偏好** | 15 March / 15th March / March 15 | 拼写形式最安全 |
| **缩写** | 15 Mar 2026 | Mar 是 March 的标准缩写 |

⚠️ **不要写错日期格式**：雅思常考"哪天出发 / 哪天到达"——用拼写形式最安全（"15th March"）。

### 时间格式

| 格式 | 写法 | 备注 |
|---|---|---|
| **12 小时制** | 2pm / 2:00 pm / two o'clock | 注意 am/pm |
| **24 小时制** | 14:00 / 1430 | 雅思较少 |
| **雅思偏好** | 2pm / 2.30pm | 简洁明确 |

### 数字格式

| 类型 | 写法 | 备注 |
|---|---|---|
| **整数** | 25 / twenty-five | 都接受 |
| **小数** | 25.5 / 25.50 | 雅思偏好简洁 |
| **百分比** | 25% / 25 percent | 雅思偏好 25% |
| **分数** | 1/4 / one quarter / a quarter | 数字形式最简洁 |
| **货币** | £30 / £30.50 / 30 pounds | 雅思接受两种 |

### 电话号码

- 通常**逐位拼读**："double 5, 9, 2, 1, 4, 7" → 5592147
- 区号："area code 020" → 020
- 国家代码："country code 44" → +44

## 五、缩写规则

### 必须展开的缩写（字数限制下）

| 听到 | 写 |
|---|---|
| "doctor" | Dr（不算 1 词；写 Dr 算 1 词） |
| "post office" | P.O. / Post Office |
| "United Kingdom" | UK / U.K. |
| "et cetera" | etc. / etc |

### 雅思可接受的缩写：
- **Jan, Feb, Mar, Apr, Jun, Jul, Aug, Sep, Oct, Nov, Dec**（月份）
- **Mon, Tue, Wed, Thu, Fri, Sat, Sun**（星期）
- **Dr, Mrs, Ms, Prof**（称谓）
- **UK, USA, EU, UN**（专有机构）
- **km, cm, kg**（度量单位）
- **am, pm**（时间）

## 七、发音陷阱 ⭐⭐⭐⭐

> 雅思听力的发音会"骗"人——有些字母不发音、有些连读会吞音。听到"好像少了一个字母"时，要还原原词拼写。

### 7.1 静默字母（不发音但要写）

| 单词 | 不发音字母 | 听到的音 | 还原拼写 |
|---|---|---|---|
| **knee** | k | /niː/ | k-n-e-e |
| **knife** | k | /naɪf/ | k-n-i-f-e |
| **castle** | t | /ˈkɑːsəl/ | c-a-s-t-l-e |
| **listen** | t | /ˈlɪsən/ | l-i-s-t-e-n |
| **often** | t（口语）| /ˈɒfən/ | o-f-t-e-n |
| **Wednesday** | 第一个 e | /ˈwenzdeɪ/ | W-e-d-n-e-s-d-a-y |
| **hour / honest / honor** | h | /aʊər/, /ˈɒnɪst/, /ˈɒnər/ | h-o-u-r, h-o-n-e-s-t |

**记忆法**：听到 /niː/ 时脑中自动补 k，写出 knee 而不是 nee。

### 7.2 数字读法陷阱

| 数字 | 错误听写 | 正确听写 | 备注 |
|---|---|---|---|
| **double 5** | 不写 5 | 5-5 | double = 两个相同数字 |
| **triple 6** | 6-6 | 6-6-6 | triple = 三个相同数字 |
| **连续 2** | 2-2 写成 22 | 2-2 | 数字 2 读 /tuː/，连续两个需精听 |
| **zero** | 不写或写 0 | 0 / zero 都可 | 电话号码常见 |

### 7.3 同音/近音词拼写区分

| 听到 | 易混 | 区分 |
|---|---|---|
| **meat**（肉） | meet（见面）| meat = 名词 /ˈmiːt/；meet = 动词 /miːt/ |
| **write / right** | 同音 | 看语义：write = 写；right = 对/右 |
| **their / there** | 同音 | their = 他们的；there = 那里 |
| **for**（功能词）| four（数字 4）| for 弱读 /fə/；four 重读 /fɔːr/ |

### 训练方法

1. **静默字母专项听写**：每天听写 5 个含静默字母的单词（knee/knife/castle/listen/Wednesday 等），听到音后还原原词拼写
2. **数字读法专项**：找 10 个电话号码/S1 数字题，标出每个数字的读法（double/triple/连续数字）
3. **同音词语义判定**：听到 meat 时先判断是"肉"还是"见面"，根据上下文判定

## 八、纸笔 vs 机考答案格式差异（2026 实操）

> 2026 年中期起全球停办纸笔考，机考为默认。

| 项目 | 纸笔（过渡期） | **机考（2026 默认）** |
|---|---|---|
| 字数限制提示 | 题卡上印 | 自动弹窗 |
| 大小写修改 | 容易（划掉重写） | 需点选修改 |
| 数字格式 | 手写 | 选择 / 输入 |
| 拼写检查 | 10 分钟誊写时可检查 | **2 分钟快速检查** |
| 空题处理 | 留空 | 标"未作答" |
| 答题顺序 | 听音时在题卡写，听完再誊写 | 边听边输入 |

**机考 2 分钟 review 必查项**（按优先级）：
1. ⭐⭐⭐⭐⭐ **字数超限**（直接 0 分）
2. ⭐⭐⭐⭐⭐ **拼写错误**（对照 20 词清单）
3. ⭐⭐⭐⭐ **单复数**（听到 -s/-es 写复数）
4. ⭐⭐⭐ **数字格式**（阿拉伯 vs 拼写）
5. ⭐⭐ **大小写**（不严判）
