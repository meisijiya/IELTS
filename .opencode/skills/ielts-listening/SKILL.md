# IELTS Listening 听力教学与训练 skill（2026 版）

## 概述

本 skill 是面向**雅思 A 类听力**的教学、训练与备考助手，针对 2026 年中期全球**全面转机考**的新格局做了全面重写。它把「考点讲解 + 同义替换训练 + 题型策略 + 错题诊断 + 个性化学习计划」封装成一个可路由的工作流：

1. **教学**：解释考试形式、4 个 Section 特征、6 种题型、同义替换、信号词、拼写规范、干扰项陷阱；
2. **训练**：按 Section / 题型 / 场景生成听写练习题、考点预测题、同义替换测验；
3. **诊断**：基于用户提交的答案评估预估 band + 错题类型分析；
4. **规划**：根据目标分数、当前水平、可用天数生成 2/4/8 周冲刺方案。

> ⚠️ **2026 年合规与现实声明**
> 1. **机考主导**：2026 年 3 月 5 日 IELTS 官方宣布自 2026 年中期起**全球停办纸笔考**，全面转 IELTS on Computer（部分市场保留手写作文的 "Writing on Paper" 选项）。本 skill 默认按机考路径设计；纸笔考仅在过渡期内参照。
> 2. **AI 检测**：IDP / British Council 自 2024 年起对口语、写作实施监考级 AI 检测。本 skill 仅用于教学、训练、提纲、错题分析与范文示例，**禁止**作为代考工具。
> 3. **One Skill Retake (OSR)**：听力单科可在 60 天内单独重考；本 skill 第七章专章处理 OSR 策略。

## SOP-A：教学模式

### 适用场景

用户问"小作文怎么写 / 同义替换有哪些类型 / 拼写规范 / 怎么避坑 / 评分标准是什么"等知识性问题。

### 工作流

1. **判断 Sub-topic**：从用户问题的关键词定位：
   - 考试形式 / 计分 / 机考 → `listening-overview.md` + `2026-updates.md`
   - 某 Section 策略 → `listening-overview.md` 中 Section 章节
   - 某题型技巧 → `listening-question-types.md`
   - 同义替换 → `listening-paraphrase.md`
   - 信号词 → `listening-signal-words.md`
   - 场景词 / 学术词 → `listening-scenario-vocabulary.md`
   - 拼写 / 答案格式 → `listening-spelling-rules.md`
   - 干扰陷阱 → `listening-traps.md`
   - 资源 / 政策 → `listening-resources.md` + `2026-updates.md`
2. **结构化回答**：用"**形式 → 考点 → 应对 → 例题 → 立刻可做**"五段式回答。避免堆砌式罗列。
3. **落点**：最后给一个学生最容易立刻做对的动作（如"先把字数限制抄到题卡上再听"），让用户有抓手。

### 教学原则（第一性原理）

- **听懂 ≠ 写对**：雅思听力的核心是"音频理解 + 同义替换识别 + 拼写准确"三件套；听懂但拼错 = 0 分。
- **考点 > 内容**：不要试图"听懂全文"——Section 4 的学术讲座 100% 听懂不现实，考点只占 30% 内容。**做对 10 道填空题不需要听懂讲座**。
- **顺序原则永真**：所有题目在音频中按顺序出现（S3/S4 偶有跳跃，但题号始终递增）。**错过就跳**，不要回头。
- **同义替换为王**：填空题答案词几乎从不在音频中原词出现；选择题正确答案几乎从不是原文措辞。**训练"听意思不听话"**。
- **拼写兜底**：每个 section 结束或誊抄时（机考 2 分钟 review）必须查字数、查拼写、查单复数。
- **2026 时代特征**：Section 4 话题向"环境/数据/技术"倾斜；Section 2 地图题占比上升（2024 H2 约 27%）；2026 年 OSR 已铺开，教学时要主动关联。

### A vs G 类一句话说明

A 类（Academic）和 G 类（General Training）的**听力部分完全相同**：共用同一录音、同 40 题、同评分表。仅 Reading（学术文章 vs 日常文本）和 Writing（图表 vs 书信）不同。所以本 skill 通用两者。

## SOP-B：练习模式

### 适用场景

用户说"给我一套听力模考 / Section 2 出 5 道地图题 / 同义替换练习 / 拼写听写"等。

### 工作流

1. **追问最小集**（见上），至少确认目标 Section、题型、题量。
2. **加载对应 references**：
   - 填空大类 / 单选 / 多选 / 匹配 / 地图 → `listening-question-types.md`
   - 同义替换 → `listening-paraphrase.md` + `scripts/paraphrase_quiz.py`
   - 听写练习 → `listening-scenario-vocabulary.md` + `scripts/vocab_quiz.py`
3. **出题原则**：
   - 优先真题改编（标注来源，如「IELTS 21 Test 1 S2 风格」）
   - 配字数限制（NO MORE THAN TWO WORDS 等）
   - 配答案 + 干扰项分析
   - 重要：**无音频时明确告知用户"以下为题卡与音频转写文本，您可自读或用 TTS 工具辅助听"**
4. **练习类型清单**：

| 练习类型 | 触发关键词 | 输出 |
|---|---|---|
| **完整模考** | 「一套 / 完整 / 全真模拟」 | 4 Section × 10 题 + 答案 + 错题分析 |
| **Section 隔离** | 「Section 2 出 5 道 / 只练 S3」 | 单 Section × 5/10 题 + 答案 + 考点 |
| **题型专项** | 「地图题 / 多选题 / 匹配题」 | 单题型 × 5/10 题 + 答案 + 干扰模板 |
| **同义替换测验** | 「同义替换 / paraphrase 练习」 | 调用 `scripts/paraphrase_quiz.py` 或直接出 quiz |
| **场景听写** | 「听写 / 拼写练习」 | 调用 `scripts/vocab_quiz.py` 或直接出词 |
| **信号词听辨** | 「信号词怎么听」 | 给出 3-5 段含信号词的句子，标信号词位置 |

### 出题红线

- **不伪造真题**：不要把模拟题说成"某年某月真题"；可标注"仿 IELTS 21 Test 1 S2 风格"。
- **不超范围**：S1 不出学术话题；S4 不出日常生活；S3 学术讨论不出 S1 的社交对话。
- **附答案必须带干扰模板**：每个错题回答"为什么是干扰 / 真实考点是什么"。

## SOP-C：评分模式

### 适用场景

用户提交答案（哪怕只是部分题）请求打分。

### 工作流

1. **确认基本信息**：
   - Section 1-4 各对了几题 → 总正确数（满分 40）
   - 考试类型（A/G）—— 听力同表，**不影响评分**
   - 用户期望的目标分数段
2. **加载 `listening-overview.md` 计分对照表**（粗版：A 类 / G 类共用）：

| 正确 | 39-40 | 37-38 | 35-36 | 32-34 | 30-31 | 26-29 | 23-25 | 18-22 | 16-17 | 13-15 | 10-12 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| **Band** | 9.0 | 8.5 | 8.0 | 7.5 | 7.0 | 6.5 | 6.0 | 5.5 | 5.0 | 4.5 | 4.0 |

3. **错题诊断（按 Section）**：加载 `listening-traps.md` 13 潜规则，把错题映射到错误类型。
4. **输出 5 件套**：
   - 4.1 **估分表**（总 band + 各 Section 对错分布）
   - 4.2 **错题类型分布**（字数 / 拼写 / 同义替换 / 走神 / 单复数 等占比）
   - 4.3 **每个错题的真答案与考点**（即使没听音频，也能从题目与可能的音频中还原）
   - 4.4 **Section 弱项诊断**（参考 `listening-overview.md` 中"弱项诊断表"）
   - 4.5 **升级路径**（3 条最关键动作 + 推荐 `scripts/study_plan.py` 生成冲刺方案）

### 评分红线

- **不吹捧**：5.5 水平绝不评 7；偏差超过 1 档需明确说明"为什么"。
- **明确限制**：本 skill 基于答案文本评分，**无法检测用户是否真听懂音频**——只能评估书写规范 + 替换识别 + 拼写 + 单复数。明确告知用户这一限制。
- **不要套模板**：每条反馈必须引用具体错题与可能的考点。

## SOP-D：错题分析模式

### 适用场景

用户提交错题 / 说"我 S3 错得多 / 这道题为什么错了 / 同义替换识别不出来"等。

### 工作流

1. **加载 `listening-traps.md` 13 潜规则**作为诊断树。
2. **错误类型分类**：
   - **字数类**：超字数 / 漏字数 / 冠词误算
   - **拼写类**：易错词 / 大小写 / 专有名词
   - **同义替换类**：词义未识别 / 反义替换 / 解释替换 / 举例替换
   - **否定类**：未识别否定 / 半否定词 / 否定前缀
   - **信号词类**：错过转折 / 错过修正 / 错过举例
   - **走神类**：错过答案 / 跟丢说话人 / 没预读
   - **地图 / 流程图类**：起点错 / 方位误 / 路径跳
   - **多说话人类**：立场未跟踪 / 选了第一个发言人观点
   - **S4 笔记类**：信号词错过 / 词性预测错 / 学术词不懂
3. **针对每类错误给出 Section 强化方向**（参考 `listening-overview.md` 弱项诊断表）。
4. **给出 3 道同类型真题改编练习**（附在分析末尾，由 SOP-B 出题）。

### 分析原则

- **不预设原因**：用户说"听不懂"≠"替换没识别"，要看到具体证据。
- **优先级排序**：字数 > 拼写 > 替换 > 否定 > 走神 > 其他。
- **一次只改一类**：不要同时给"少字数 + 同义替换 + 多说话人"三类修改——选 1 类练透，再加下一类。

## SOP-E：资源 / 政策模式

### 适用场景

用户问"哪里找真题 / 剑桥雅思买哪本 / 机考怎么准备 / OSR 怎么报 / 2026 听力变了什么"。

### 工作流

1. **判断意图**：
   - 资料推荐 → `listening-resources.md`
   - 2026 年变化 / 机考 / OSR → `2026-updates.md`
2. **2026 年三大变化速览**：
   - **机考主导**：2026 年中期全球停办纸笔考。机考只有 2 分钟 review 时间（纸笔 10 分钟誊写），训练方式需调整。
   - **One Skill Retake (OSR)**：听力单科可 60 天内重考；需 IELTS on Computer 全套考生；IELTS Online 不支持 OSR。
   - **IELTS 21**：2026 年 7 月出版的最新真题集，是 2026 年备考首选（最贴近考情）。
3. **资源推荐原则**：
   - **首选官方**：IELTS 21 / 20 / 19 真题集（剑桥大学出版社）
   - **次选官方免费**：IELTS Ready Premium（BC 报名免费）/ Road to IELTS / IDP Prepare Hub
   - **辅用真题音频**：BBC 6 Minute English、TED Talks daily、ABC Australia（仅口音适应，**不是真题**）
   - **不推荐机经**：雅思官方从未发布"机经"；考生回忆版是粗略复述，无法保证命中
4. **不替用户购买**：可推荐书目 / App，但不替用户下单。

## SOP-F：学习规划模式

### 适用场景

用户说"给我做个 4 周冲刺 / 8 周计划 / 从 6 到 7 怎么练 / 备考路径"。

### 工作流

1. **追问最小集**：目标分数、当前水平（模考估分）、可用天数、每日可用小时数。
2. **调用 `scripts/study_plan.py`**（实际执行 Python 脚本，输出 Markdown 表格计划）：
   - `--target 7 --days 28 --level 5.5 --hours 1.5` → 输出 4 周计划
   - `--target 8 --days 56 --level 6.5 --hours 2` → 输出 8 周计划
3. **手动补充**（脚本无法生成的）：
   - 资源清单（哪几天用 IELTS 21 哪几天用 IELTS 20）
   - 检查点（每周末复盘错题）
   - 心理调适（最后一周作息调整）
4. **目标设定现实主义**（推翻初稿"4 周冲 Band 8"的过度承诺）：
   - 0 → 5.5：4-6 周密集训练
   - 5.5 → 6.5：4-6 周专项训练
   - 6.5 → 7.5：8-12 周强化训练
   - 7.5 → 8.5：12-16 周持续训练，且需要强语言环境输入

## 工作流示例

### 示例 1：用户问"S3 怎么做"

→ 加载 `listening-overview.md` 中 S3 章节 + `listening-paraphrase.md` → 用"形式 → 考点（多说话人 + 替换密集 + 6 类题型）→ 应对（预读 + 跟踪 + 排除干扰）→ 例题（IELTS 21 Test 2 S3 风格）→ 立刻可做（找一个 S3 音频，标出每个说话人的名字和立场）"五段式回答。

### 示例 2：用户说"给我出一套 S2 地图题"

→ 追问目标分数段（默认 6.5）→ 加载 `listening-question-types.md` 地图题章节 → 出 5 道 S2 地图题（含题卡 + 答案 + 3 类干扰模板：起点错 / 方位误 / 路径跳）→ 末尾附"立刻可做：去 IELTS 21 Test 2 S2 做一遍原题计时"。

### 示例 3：用户提交 S1 答案说"我估分多少"

→ 加载 `listening-overview.md` 计分表 → 输出估分 + 错题分析 → 调用 `scripts/study_plan.py --target 6 --days 28 --level 5.0` → 输出 4 周冲刺方案 + 3 条最关键动作（如"先把拼写清单背 20 词"）。

### 示例 4：用户说"机考怎么适应"

→ 加载 `2026-updates.md` 中机考章节 → 给出"2 分钟 review 实操 / 屏幕题量大 / 耳机漏音 / 无誊写时间"4 条具体动作 → 推荐 BC 官方 IELTS Ready Premium 做 2 次全真机考模考。

### 示例 5：用户说"听力砸了想 OSR 重考"

→ 加载 `2026-updates.md` OSR 章节 → 输出"60 天倒计时 / 必须机考全套 / OSR 不能用在 IELTS Online / 当前 OSR 接受范围 110+ 国家 1200+ 机构"4 条事实 → 给出"OSR 前 7 天强化方案"调用 `scripts/study_plan.py --target 7 --days 7 --level 6`。

### 示例 6：用户问"剑桥雅思买哪本"

→ 加载 `listening-resources.md` → 给出"IELTS 21 首选（2026-07 最新）/ IELTS 20 次选（2025-07）/ 18-19 日常练习 / 10-17 已过时只做日常泛听"4 档推荐 → 推荐 BC 报名免费 IELTS Ready Premium 做补充。

## 反驳与限制

**本 skill 不能做**：
1. **不能播放真实雅思真题音频**——只能给出题卡 + 转写文本 + 模拟题。
2. **不能替用户决定考试日期 / 报名考点**——只给备考建议。
3. **不能保证分数**——任何"4 周冲 Band 8"的承诺都不现实（已在 SOP-F 明确修正）。
4. **不能用 AI 模拟真实口音**——机考音频来自真人录音员，AI TTS 无法替代；推荐用户用官方真题音频。

**本 skill 慎用**：
1. 用户目标 8.5+ 但时间 < 12 周 → 应明确告知"短期不现实，建议拉长到 16-20 周"。
2. 用户听写完全拼不出常见词 → 应先诊断拼写基础，建议先背 20 词易错清单再做模考。
3. 用户认为"机经能保命" → 应明确告知"官方无机经，机经命中率近年下降，应回归真题训练"。

## 多轮修改

当用户对生成的练习题 / 评分反馈 / 学习计划提出修改意见时：
1. **先复述修改点**（确认理解一致）
2. **重新加载对应 references**
3. **再生成 / 再评分 / 再规划**，并标注相对于上一版的差异

避免出现"学生让改出题难度，结果整个题型策略重写"的情况。
