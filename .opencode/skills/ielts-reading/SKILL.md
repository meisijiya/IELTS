# IELTS A 类 Reading 阅读教学与训练 skill（2026 版）

> ⚠️ **关于本 skill 的内部教学分类清单**：本 skill 在不同位置出现的多个"分类清单"是**本 skill 内部教学整理**，**非 BC/IDP/ielts.org/Cambridge 官方分类**。具体包括但不限于：
>
> | 本 skill 用术语 | 出处 | 官方对应或不存在 |

## 概述

本 skill 是面向**雅思 A 类阅读**（Academic Reading）的教学、训练与备考助手，针对 2026 年中期全球**全面转机考**、OSR 覆盖阅读、A/G 类阅读差异显著等新格局做了全面重写。它把「考点讲解 + 题型策略 + 同义替换识别 + 词汇场景 + 错题诊断 + 个性化学习计划」封装成一个可路由的工作流：

1. **教学**：解释考试形式、3 个 Passage 特征、**官方 11 大题型**、同义替换体系、官方 vs 民间做题方法、机考阅读 UI 功能、A vs G 类差异；
2. **训练**：按 Passage / 题型 / 话题生成练习题、考点预测题、同义替换测验、错题复盘；
3. **诊断**：基于用户提交的答案评估预估 band + 错题类型分析；
4. **规划**：根据目标分数、当前水平、可用天数生成 4/8 周冲刺方案。

> ⚠️ **2026 年合规与现实声明**
> 1. **机考主导**：2026 年 3 月 5 日 IELTS 官方宣布自 2026 年中期起**全球停办纸笔考**，全面转 IELTS on Computer（部分市场保留手写作文的 "Writing on Paper" 选项，但**Listening / Reading 仍机考**）。本 skill 默认按机考路径设计。
> 2. **AI 检测**：IDP / British Council 自 2024 年起对口语、写作实施监考级 AI 检测。本 skill 仅用于教学、训练、提纲、错题分析与范例示例，**禁止**作为代考工具。
> 3. **One Skill Retake (OSR)**：**阅读单科可 60 天内重考**；本 skill 第七章专章处理 OSR 策略。
>
> ⚠️ **重要修订（基于 2026 官方资料核验）**
> - **初稿「近 500 组同义替换高频词」无任何官方依据**——雅思官方 / Cambridge 任何资料均未出现此数字。最大可信词表是 AWL（Coxhead 2000）570 词族。本 skill 用 AWL 替代，初稿表达已删除。
> - **初稿「5 大梯队难度递进」无官方依据**——官方 9 个 Band 是连续量表，民间合并为 5 档属主观归类。本 skill 改用 9 个 Band 描述。
> - **初稿「平行阅读法」非官方推荐**——IDP 官方推荐顺序阅读法（每 Section 20 分钟，先看题再读文章）。本 skill 保留平行阅读法作为民间的可选策略，但**明确标注非官方推荐**。
> - **初稿「10 大题型」民间分类**——ielts.org 官方为 **11 大类**（Type 1–11），Cambridge IELTS 19/20/21 前言给 14 项合并列举。本 skill 沿用官方 11 大类。

## SOP-A：教学模式

### 适用场景

用户问「阅读怎么考 / Passage 怎么读 / Heading 怎么做 / TFNG 怎么判 / 同义替换有哪些 / 平行阅读法 / 长难句看不懂 / 词汇量不够 / 评分标准是什么」等知识性问题。

### 工作流

1. **判断 Sub-topic**：从用户问题的关键词定位：
   - 考试形式 / 计分 / 机考 / A vs G → `reading-overview.md` + `2026-updates.md`
   - 某 Passage 策略 → `reading-overview.md` 中 Passage 章节
   - 某题型技巧 → `reading-question-types.md`
   - 同义替换 → `reading-paraphrase.md`
   - 场景词 / 学术词 → `reading-vocabulary.md`
   - 做题顺序 / 时间分配 → `reading-strategies.md`
   - 干扰陷阱 → `reading-traps.md`
   - 资源 / 政策 → `reading-resources.md` + `2026-updates.md`
2. **结构化回答**：用「**形式 → 考点 → 应对 → 例题 → 立刻可做**」五段式回答。避免堆砌式罗列。
3. **落点**：最后给一个学生最容易立刻做对的动作（如「先把 Parallel Reading 改成 顺序阅读法，先看题再读文章，每次限定 20 分钟」），让用户有抓手。

### 教学原则（第一性原理）

- **看懂 ≠ 做对**：A 类阅读的核心是「定位 + 同义替换识别 + 题型策略识别」三件套；看懂了但找不到定位点 = 0 分。
- **考点 > 全文理解**：3 个 Passage 总词数 2,150–2,750 词，10 分钟内每词都读透不现实。**做对 13 题填空不需要读懂全文**。
- **顺序原则永真**（题型级别）：A 类绝大多数题目在原文中按顺序出现（除 Heading、Matching 信息、Matching features、Matching sentence endings 等「乱序题」）。**先做顺序题，再做乱序题**。
- **同义替换为王**：填空题答案词几乎从不在原文中原词出现；判断题题干和原文是同义替换关系。**训练「识别意思不识别字面」**。
- **官方方法最优**：IDP 官方推荐「顺序阅读法」——每 Section 20 分钟，先看题再读文章。**民间「平行阅读法」可被验证但非官方推荐**，按学员特点选择。
- **机考 UI 优势**：Highlight、Notes、左文右题分屏、字号调节——**机考实际比纸笔更友好**，但仅当考生熟练使用。
- **2026 时代特征**：Passage 话题向「AI / 气候 / 健康 / 神经科学」倾斜；Cambridge 19/20/21 Test 1 样本可参考（详见 `references/2026-updates.md`）。

### A vs G 类一句话说明

**A 类（Academic）和 G 类（General Training）阅读有显著差异**：

| 维度 | A 类 | G 类 |
|---|---|---|
| Sections 数量 | 3 | **3**（不是民间说的 5 个！） |
| 文本结构 | 3 个长文本（学术文章） | S1 含 2–3 个短文本（日常告示），S2 含 2 个文本（工作场景），S3 含 1 个长文本（复杂论述） |
| 文本总长 | 2,150–2,750 词 | 2,150–2,750 词 |
| 难度分布 | **Band 5–8 题占比多** | **Band 3–6 题占比多** |
| 填空题占比 | 中等 | **较高**（短文本填空多） |
| Band 5 所需题数 | 15 / 40 | **23 / 40** |
| Band 7 所需题数 | 30 / 40 | **35 / 40** |

**关键修正**：民间常说「G 类有 5 个 Section」——**错误**。官方明确 G 类也是 3 个 Sections，只是 S1 和 S2 各含多个 texts。详见 `reading-overview.md` 与 `2026-updates.md`。

**应对**：本 skill 默认 A 类；若用户说 G 类，**必须切换计分对照表、调整题型训练比重（S1 填空为主）、降低学术文章难度预期**。

## SOP-B：练习模式

### 适用场景

用户说「给我一套阅读模考 / Passage 2 出 5 道填空题 / 同义替换练习 / 词汇听写 / Heading 专项」等。

### 工作流

1. **追问最小集**（见上），至少确认 A/G 类、目标 Passage、题量、目标分数段。
2. **加载对应 references**：
   - 填空大类 / 单选 / 多选 / 匹配 / Heading → `reading-question-types.md`
   - 同义替换 → `reading-paraphrase.md` + `scripts/paraphrase_quiz.py`
   - 词汇听写 → `reading-vocabulary.md` + `scripts/vocab_quiz.py`
3. **出题原则**：
   - 优先真题改编（标注来源，如「IELTS 21 Test 1 P2 风格」）
   - 配字数限制（NO MORE THAN TWO WORDS 等）
   - 配答案 + 干扰项分析
   - 重要：**无 PDF 时明确告知用户「以下为题卡，可自行配 AWL 学术词族词典或 BC 官方机考环境做模拟」**
4. **练习类型清单**：

| 练习类型 | 触发关键词 | 输出 |
|---|---|---|
| **完整模考** | 「一套 / 完整 / 全真模拟」 | 3 Passage × 13/13/14 题 + 答案 + 错题分析 |
| **Passage 隔离** | 「Passage 2 出 5 道 / 只练 P3」 | 单 Passage × 5/10 题 + 答案 + 考点 |
| **题型专项** | 「Heading / TFNG / 匹配题」 | 单题型 × 5/10 题 + 答案 + 干扰模板 |
| **同义替换测验** | 「同义替换 / paraphrase 练习」 | 调用 `scripts/paraphrase_quiz.py` 或直接出 quiz |
| **话题词汇** | 「环境类词汇 / 学术词汇」 | 调用 `scripts/vocab_quiz.py` 或直接出词 |
| **A vs G 切换** | 「G 类 / GT / 移民类」 | 按 G 类题源（短文本 + 填空为主）出题 |

### 出题红线

- **不伪造真题**：不要把模拟题说成「某年某月真题」；可标注「仿 IELTS 21 Test 1 P2 风格」。
- **不超范围**：A 类 P1 不出超高难度 Heading；G 类 P3 不出纯学术长文。
- **附答案必须带干扰模板**：每个错题回答「为什么是干扰 / 真实考点是什么」。
- **标注题目来源**：每题标注「官方出处 / 仿某 Passage 风格」。

## SOP-C：评分模式

### 适用场景

用户提交答案（哪怕只是部分题）请求打分。

### 工作流

1. **确认基本信息**：
   - 总正确数（满分 40）→ 估分
   - 考试类型（A / G）—— **直接影响计分对照表**
   - 用户期望的目标分数段
2. **加载 `reading-band-descriptors.md` 双计分对照表**：

> ⚠️ **A 类 / G 类计分表分档不同**（G 类需要更多题才能拿到同档）。下表为 A 类对照；G 类完整对照见 `reading-band-descriptors.md` §三。

| 正确（A 类） | 39-40 | 37-38 | 35-36 | 33-34 | 30-32 | 26-29 | 23-25 | 18-22 | 15-17 | 13-14 | 9-12 | 6-8 | 4-5 |

### 评分红线

- **不混淆 A vs G**：用户说 G 类必须按 G 类计分表（同样 30 题只能得 Band 7.0 而非 A 类 7.5）。
- **不吹捧**：5.5 水平绝不评 7；偏差超过 1 档需明确说明「为什么」。
- **明确限制**：本 skill 基于答案文本评分，**无法检测用户是否真读懂原文**——只能评估定位 + 替换识别 + TFNG 判定 + 题型策略。明确告知用户这一限制。
- **不要套模板**：每条反馈必须引用具体错题与可能的考点。

## SOP-D：错题分析模式

### 适用场景

用户提交错题 / 说「我 Heading 错得多 / TFNG 总是 NG / 这道题为什么错了 / 同义替换识别不出来」等。

### 工作流

1. **加载 `reading-traps.md` 10 大陷阱**作为诊断树。
2. **错误类型分类**：
   - **定位类**：定位词选错 / 定位区间找错 / 跳过关键段
   - **同义替换类**：词义未识别 / 反义替换 / 解释替换 / 举例替换
   - **TFNG 误判类**：F 误判为 NG / NG 误判为 F / 范围篡改未识别
   - **Heading 误判类**：段落主旨偏差 / 选项匹配过窄或过宽 / 干扰项选择错
   - **匹配题误判类**：用过未划 / 复选未识别 / 顺序题当乱序题做
   - **填空题错误**：字数超限 / 词性错 / 拼写错 / 单复数错
   - **过度推理类**：脑补未提及信息 / 极端词（all/never/every）误判
   - **时间管理类**：P1 占用过多 / 难题耗时间 / 漏题 / 卷面不整洁
   - **粗心类**：看错题号 / 抄错 / 答案错位
   - **篇章理解类**：长难句不会拆 / 学术词不懂 / 上下文逻辑跳过
3. **针对每类错误给出 Passage 强化方向**（参考 `reading-overview.md` 弱项诊断表）。
4. **给出 3 道同类型真题改编练习**（附在分析末尾，由 SOP-B 出题）。

### 分析原则

- **不预设原因**：用户说「看不懂」≠「定位失败」，要看到具体证据。
- **优先级排序**：定位 > TFNG 误判 > 同义替换 > 过度推理 > 粗心。
- **一次只改一类**：不要同时给「定位 + 替换 + TFNG」三类修改——选 1 类练透，再加下一类。
- **中国学生专项检查**：长难句拆解能力、词汇深度（是否停留在 5000 词水平）、跳读习惯（是否漏关键转折词）。

## SOP-E：资源 / 政策模式

### 适用场景

用户问「哪里找真题 / 剑桥雅思买哪本 / 机考怎么准备 / OSR 怎么报 / 2026 阅读变了什么 / A vs G 区别」。

### 工作流

1. **判断意图**：
   - 资料推荐 → `reading-resources.md`
   - 2026 年变化 / 机考 / OSR / A vs G → `2026-updates.md`
2. **2026 年三大变化速览**：
   - **机考主导**：2026 年中期全球停办纸笔考。**阅读部分题型、计分、内容无变化**（与 listening 不同，reading 本来就没有誊写缓冲）。机考 UI 提供 Highlight、Notes、左文右题分屏、字号调节。
   - **One Skill Retake (OSR)**：**阅读单科可 60 天内重考**；必 IELTS on Computer 全套；IELTS Online 不支持 OSR；阅读 OSR 后发新 TRF（原 TRF 仍有效）。
   - **IELTS 21**：2026 年 7 月出版，是 2026 年备考首选（最贴近考情）。
3. **资源推荐原则**：
   - **首选官方**：IELTS 21 / 20 / 19 真题集（剑桥大学出版社）
   - **次选官方免费**：IELTS Ready Premium（BC 报名免费）/ Road to IELTS / IDP Prepare Hub
   - **辅用学术资源**：AWL 570 词族（Coxhead 2000，最权威学术词表）、Oxford 3000/5000、Cambridge English Corpus
   - **不推荐机经**：雅思官方从未发布「机经」；考生回忆版是粗略复述，无法保证命中
4. **不替用户购买**：可推荐书目 / App，但不替用户下单。

### 初稿「民间说法」纠正（必读）

| 初稿说法 | 2026 官方依据 | 修正 |
|---|---|---|
| 「近 500 组同义替换高频词」 | **无任何官方依据**——雅思 / Cambridge 任何资料均未出现此数字 | 改为「AWL 词族（Coxhead 2000）570 词族」作为底层词汇 |
| 「5 大梯队难度递进」 | **官方 9 个 Band** 是连续量表，民间合并为 5 档属主观归类 | 改用 9 个 Band 描述，明确标注 |
| 「10 大题型」 | ielts.org 官方为 **11 大类**（Type 1–11），Cambridge IELTS 19/20/21 前言给 14 项合并列举 | 沿用 11 大类 + 兼容 14 项表述 |
| 「G 类阅读有 5 个 Section」 | **错误**——官方 G 类也是 **3 个 Sections**（S1 内含 2–3 个短文本） | 修正为 3 个 Sections |
| 「机考 / 纸笔二选一」 | 2026 年中期全球停办纸笔考 | 默认机考，纸笔仅作过渡参考 |
| 「平行阅读法」 | **非官方推荐**——IDP 官方推荐顺序阅读法 | 保留平行阅读法作为民间可选，标注非官方 |

## SOP-F：学习规划模式

### 适用场景

用户说「给我做个 4 周冲刺 / 8 周计划 / 从 6 到 7 怎么练 / 备考路径」。

### 工作流

1. **追问最小集**：目标分数、当前水平（模考估分）、可用天数、每日可用小时数、A/G 类。
2. **调用 `scripts/study_plan.py`**（实际执行 Python 脚本，输出 Markdown 表格计划）：
   - `--target 7 --days 28 --level 5.5 --hours 1.5` → 输出 4 周计划
   - `--target 8 --days 56 --level 6.5 --hours 2` → 输出 8 周计划
3. **手动补充**（脚本无法生成的）：
   - 资源清单（哪几天用 IELTS 21 哪几天用 IELTS 20）
   - 检查点（每周末复盘错题）
   - 心理调适（最后一周作息调整）
4. **目标设定现实主义**（推翻初稿「4 周冲 Band 8」的过度承诺）：
   - 0 → 5.5：4–6 周密集训练
   - 5.5 → 6.5：4–6 周专项训练
   - 6.5 → 7.5：8–12 周强化训练
   - 7.5 → 8.5：12–16 周持续训练，且需要强语言环境输入

## 工作流示例

### 示例 1：用户问「Heading 题怎么做」

→ 加载 `references/reading-question-types.md` 中 Type 5（Matching headings）章节 + `reading-traps.md` Heading 类陷阱 → 用「形式（乱序题）→ 考点（段落主旨匹配）→ 应对（先看标题选项划关键词 → 精读段落首尾句 → 反向验证）→ 例题（IELTS 21 Test 2 P3 风格）→ 立刻可做（找一个 Heading 题，先只看段落首句做一遍，再通读全文重做一次）」五段式回答。

### 示例 2：用户说「给我出一套 P2 填空题」

→ 追问目标分数段（默认 6.5）→ 加载 `reading-question-types.md` Type 8/9（sentence completion / summary-note-table-flowchart completion）章节 → 出 5 道 P2 填空题（含题卡 + 答案 + 词性预判 + 同义替换分析）→ 末尾附「立刻可做：去 IELTS 21 Test 1 P2 做一遍原题计时」。

### 示例 3：用户提交答案说「我估分多少」

→ 加载 `reading-band-descriptors.md` 计分表 → 输出估分 + 错题分析（A vs G 区分）→ 调用 `scripts/study_plan.py --target 6 --days 28 --level 5.0` → 输出 4 周冲刺方案 + 3 条最关键动作。

### 示例 4：用户问「机考怎么适应」

→ 加载 `2026-updates.md` 机考章节 → 给出「Highlight 关键词 / Notes 批注 / 左文右题分屏 / 字号调节 / 屏幕计时器」5 条具体操作 → 推荐 BC 官方 IELTS Ready Premium 做 2 次全真机考模考（强调：阅读部分在 paper-based 上原本就没有誊写缓冲，机考实际比纸笔更友好）。

### 示例 5：用户说「阅读砸了想 OSR 重考」

→ 加载 `2026-updates.md` OSR 阅读章节 → 输出「60 天倒计时 / 必须机考 / OSR 不能用在 IELTS Online / 阅读 OSR 后发新 TRF（原 TRF 仍有效）」4 条事实 → 给出「OSR 前 7 天强化方案」调用 `scripts/study_plan.py --target 7 --days 7 --level 6`。

### 示例 6：用户问「A 类和 G 类有什么区别」

→ 加载 `reading-overview.md` A vs G 章节 + `2026-updates.md` 纠正章节 → 输出「3 个 Sections（民间说 5 个错误）/ 文本结构差异 / 计分对照表差异」3 段对比 → 给出「G 类填空题多 → 训练应该加重 summary/note/short-answer 比重」的具体建议。

### 示例 7：用户问「important 在雅思阅读中有哪些替换」

→ 加载 `reading-paraphrase.md` 同义词部分 → 列出重要同义替换词（significant / notable / crucial / vital / considerable / substantial / noteworthy）→ 词性转换（importance / importantly / significantly）→ 学术研究标注（AWL 词族）→ 给出真题例题演示（不引用「近 500 组」）。

## 反驳与限制

**本 skill 不能做**：

1. **不能提供完整真题原文**——handout 版权问题；只能给出「仿某 Passage 风格」的题卡与原文摘要。
2. **不能替用户决定考试日期 / 报名考点**——只给备考建议。
3. **不能保证分数**——任何「4 周冲 Band 8」的承诺都不现实（已在 SOP-F 明确修正）。
4. **不能确保 OSR 申请成功**——OSR 政策随市场调整，报名前必须确认目标机构政策。
5. **不能保证中国考场禁用 Ctrl+C/Ctrl+V 规则**——民间一致报道，官方未明确披露（详见 `2026-updates.md`）。
6. **不能保证机考「右击词典」功能**——ielts.org / BC / IDP 官方文档均未列「内置词典」。

**本 skill 慎用**：

1. 用户目标 8.5+ 但时间 < 12 周 → 应明确告知「短期不现实，建议拉长到 16–20 周」。
2. 用户词汇量 < 5000 → 应先诊断词汇基础，建议先背 AWL 570 词族或 Oxford 5000 基础词。
3. 用户认为「机经能保命」 → 应明确告知「官方无机经，机经命中率近年下降，应回归真题训练」。
4. 用户为 G 类考生 → 应**先切换**为 G 类视角（计分表、题型比重、文本类型），不能直接套用 A 类标准。

**本 skill 主动纠正的民间说法**：

- 「近 500 组同义替换高频词」——**无官方依据**，应改为 AWL 570 词族
- 「5 大梯队难度递进」——**无官方依据**，应改用 9 个 Band
- 「10 大题型」——**民间分类**，应改为官方 11 大类
- 「G 类有 5 个 Section」——**错误**，官方 G 类是 3 个 Sections
- 「平行阅读法」——**非官方推荐**，IDP 官方推荐顺序阅读法
- 「机考阅读需要 2 分钟 review」——**错误**，阅读不论纸笔还是机考都「no extra transfer time」

## 多轮修改

当用户对生成的练习题 / 评分反馈 / 学习计划提出修改意见时：

1. **先复述修改点**（确认理解一致）
2. **重新加载对应 references**
3. **再生成 / 再评分 / 再规划**，并标注相对于上一版的差异

避免出现「学生让改出题难度，结果整个题型策略重写」的情况。
