# Reading Strategies：顺序阅读法（官方推荐）+ 平行阅读法（民间，标注）+ 4 周计划

> 2026 版。**初稿「平行阅读法」表述为权威方法，已修正**——IDP 官方推荐「顺序阅读法」，平行阅读法属民间策略。本文件给两种方法 + 时间分配 + 4/8 周计划 + 跳读略读技巧。

---

## ⚠️ 重要修正

**初稿「平行阅读法」表述**：

> "先读完该篇文章对应的所有题目 → 划出所有题目的关键词 → 读文章时每读完一段就去题目中核对。"

**核验结果**：

- **IDP 官方推荐顺序阅读法**：
  > "You have 60 minutes to complete 40 questions on the test, so managing your time is crucial. There are three sections in the Reading test, and you should aim to **spend no more than 20 minutes on each section**."
  > ——[ielts.idp.com Time Management](https://ielts.idp.com/prepare/article-how-to-manage-your-time-during-the-ielts-test)
- **官方推荐「先看题再读文章」**：
  > "**Read the questions before you read the text**"
  > ——IDP 官方
- **Weir et al. 2009 学术研究**：高分组考生 83% 使用「快速匹配关键词」+ 77% 使用「回读相关部分」，但**该研究描述考生自然策略，非官方推荐**

**修正方案**：

- **默认推荐顺序阅读法**（IDP 官方）
- **保留平行阅读法作为民间可选策略**，但**明确标注非官方推荐**
- **学员可两种方法都尝试 3 套题**，按自己节奏决策

## 一、两种方法对比

### 方法 A：顺序阅读法（IDP 官方推荐）

**步骤**：

1. **进入 Passage / 题目区** → 先看题目（5 分钟）
2. **划出题目关键词**（人名 / 数字 / 专有名词）
3. **划出题目字数限制**（NO MORE THAN...）
4. **读 Passage**（找题目关键词的同义替换）
5. **逐题作答**（按题目顺序）
6. **Passage 结束** → 进入下一 Passage（20 分钟硬上限）

**适用场景**：

- ✅ 顺序题（填空 / TFNG / 单选）为主
- ✅ 所有官方推荐场景
- ✅ 0 → 7.0 学员

**优势**：

- 官方推荐
- 时间盒可控（20 分钟 / Passage）
- 顺序题效率高

**劣势**：

- 乱序题（Heading / 匹配）耗时较长
- 需要多次回读

### 方法 B：平行阅读法（民间，标注）

**步骤**：

1. **一次性读完 P1+P2+P3 所有题目**（10 分钟）
2. **划出所有题目的关键词**
3. **读 P1 原文** → 每读完一段就回所有题目核对
4. **P1 答完** → 进入 P2
5. **P2 答完** → 进入 P3

**适用场景**：

- ⚠️ 民间策略（**非官方推荐**）
- ✅ 乱序题（Heading / 匹配）为主
- ✅ 7.0+ 学员（高速处理）
- ✅ P1 / P2 较简单时

**优势**：

- 乱序题效率高
- 减少重复回读

**劣势**：

- ⚠️ **非官方推荐**
- 时间管理难度高（容易 P1 占用过多）
- 心理压力大（一次性处理 40 题）

## 二、官方推荐时间分配

### IDP 官方推荐

| Passage | 目标时长 | 难度 |
|---|---|---|
| **P1** | **18–20 分钟**（不超过 20 分钟） | ⭐⭐ |
| **P2** | **20 分钟** | ⭐⭐⭐ |
| **P3** | **20–22 分钟** | ⭐⭐⭐⭐⭐ |

### 实战分配

| 阶段 | 时间 | 任务 |
|---|---|---|
| **0–2 分钟** | 进入 P1 | 扫读所有题目，划关键词 |
| **2–18 分钟** | P1 答题 | 读 P1 原文 + 逐题作答 |
| **18–20 分钟** | 收尾 | 检查 P1 答案 |
| **20–22 分钟** | 进入 P2 | 扫读所有题目，划关键词 |
| **22–40 分钟** | P2 答题 | 读 P2 原文 + 逐题作答 |
| **40–42 分钟** | 收尾 | 检查 P2 答案 |
| **42–44 分钟** | 进入 P3 | 扫读所有题目，划关键词 |
| **44–60 分钟** | P3 答题（**预留完整 20 分钟**） | 读 P3 原文 + 逐题作答 |
| **60 分钟** | 收尾 | 最后一遍检查 |

## 三、跳读 / 略读 / 扫读技巧

### 跳读（Skimming）

**目的**：快速了解 Passage 主旨

**方法**：

- 读每段首句（段旨句）+ 末句（总结句）
- 扫读关键词（sustainable / demonstrate / conclude 等）
- 忽略举例 / 解释 / 修饰

**适用**：进入 Passage 时的「热身扫读」

### 略读（Scanning）

**目的**：找特定信息

**方法**：

- 用题目关键词（具体名词 / 数字 / 专有名词）回原文搜索
- 找到目标位置 → 精读周围 2–3 句

**适用**：填空题 / TFNG / 单选（找定位）

### 扫读（Reading for Detail）

**目的**：理解段落细节

**方法**：

- 慢速精读，关注每句的逻辑关系
- 注意转折词（but / however / although）

**适用**：Heading / 复杂匹配（需要理解段落功能）

### 实战组合

| 题型 | 用什么方法 |
|---|---|
| **填空题** | 略读（找定位）→ 扫读（定位周围） |
| **TFNG** | 略读（找定位）→ 扫读（精读题目句） |
| **单选** | 略读（找定位）→ 扫读（精读选项） |
| **Heading** | 跳读（每段首尾句）→ 选项匹配 |
| **匹配题** | 略读（找定位）→ 扫读（匹配选项） |
| **YNNG** | 跳读（识别作者表述）→ 扫读（精读） |

## 四、4 周强基 / 8 周强化 / 12 周冲刺计划

### 4 周强基（目标 5.0 → 6.0）

| 周 | 重点 | 每天 |
|---|---|---|
| **W1** | AWL 词族前 200 词 + P1 填空 30 题 + 顺序阅读法训练 | 1.5 小时 |
| **W2** | AWL 词族 200–400 + 顺序题综合 30 题（P1+P2） | 1.5 小时 |
| **W3** | TFNG 专项 30 题 + 错题复盘 + 顺序阅读法强化 | 2 小时 |
| **W4** | 2 套完整模考（IELTS 19 Test 1 + IELTS 20 Test 1）+ 复盘 + 心理调适 | 2.5 小时 |

**目标**：4 周后模考能稳定 5.5–6.0

### 8 周强化（目标 6.0 → 7.0）

| 周 | 重点 | 每天 |
|---|---|---|
| **W1-2** | AWL 词族 400–570 + P1/P2 顺序题综合 + 顺序阅读法强化 | 1.5 小时 |
| **W3-4** | TFNG + Heading 专项 + 错题分类 + 顺序阅读法测试 | 2 小时 |
| **W5-6** | 平行阅读法实验（仅实验）+ 乱序题综合（Heading / Matching） | 2 小时 |
| **W7-8** | 4 套完整模考（IELTS 19/20/21 各 1 + 一套加练）+ 错题复盘 + 心理调适 | 2.5 小时 |

**目标**：8 周后模考能稳定 6.5–7.0

### 12 周冲刺（目标 7.0 → 8.0+）

| 周 | 重点 | 每天 |
|---|---|---|
| **W1-4** | AWL 词族全覆盖 + 8 大话题词汇 + 顺序题 + TFNG + 顺序阅读法 | 2 小时 |
| **W5-8** | Heading + 复杂匹配 + 平行阅读法深度实验 + 精读学术文章（The Economist / Nature） | 2.5 小时 |
| **W9-12** | 8 套完整模考（IELTS 19/20/21 全部）+ 错题复盘 + 平行阅读法 + 学术阅读拓展 | 3 小时 |

**目标**：12 周后模考能稳定 7.5–8.0

## 五、每日训练时间表（冲刺版）

### 早晨 30 分钟（推荐：起床后）

- AWL 词族复习（Anki 卡片）
- 熟词僻义 10 个

### 下午 1 小时（推荐：精力最高时段）

- 真题训练（按 Passage / 题型）
- 错题复盘

### 晚上 30 分钟（推荐：睡前）

- 学术阅读（The Economist / Nature / Science 短文）
- 整理笔记

### 周末（2–3 小时）

- 1 套完整模考（计时）
- 错题复盘 + 下周计划

## 七、应试心理调适

### 考前 1 周

- 每天 1 套完整模考（找考试节奏）
- 调整作息（早睡早起）
- **不要做新题**——只复习错题

### 考前 1 天

- 轻量复习（看错题本 + 高频词）
- 准备考试用品（准考证 / 身份证 / 铅笔等）
- **不要做大题**——只做 5 题填空热身

### 考前 30 秒

- 深呼吸 3 次
- 默念「按 20 分钟 / Passage，先看题再读文章，每 5 分钟检查进度」
- 进入机考 UI 后 → 调整字号 → 熟悉屏幕

### 考试中

- P1 错 2 题别慌（正常）
- P3 难题标记 → 跳过 → 回来再战
- 5 分钟倒数时填完所有 Review 标记题

### 考试后

- 不对答案（影响下一场）
- 回酒店休息
- 准备下一场

## 八、推荐做题顺序（按学员水平）

### 0 → 6.0 学员

1. **P1（顺序题为主）** → 必全对
2. **P2（顺序题 + TFNG）** → 重点训练
3. **P3（乱序题）** → 跳过难题

### 6.0 → 7.0 学员

1. **P1（必全对）** → 抢时间
2. **P2（顺序题 + TFNG）** → 重点训练
3. **P3（Heading + 匹配）** → 平行阅读法实验

### 7.0+ 学员

1. **P1（必全对）** → 抢时间
2. **P2（顺序题 + TFNG）** → 必稳
3. **P3（复杂匹配 + Heading）** → 深度训练

## 九、立刻可做的 3 个动作

1. **确定方法**：先选顺序阅读法（默认）→ 3 套题后决定是否测试平行阅读法
2. **打印时间盒**：每 Passage 20 分钟 → 用计时器强制
3. **做 1 套模考**（IELTS 21 Test 1）→ 验证时间分配是否合理
