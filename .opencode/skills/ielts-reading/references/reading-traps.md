## 二、10 大陷阱详解

### 陷阱 1：定位失败

**症状**：

- 找不到答案对应的原文位置
- 找了很久找不到，浪费 5+ 分钟

**原因**：

- **定位词选错**：用了「题目里」但在「原文里」不存在的词
- **定位区间找错**：找到了，但跳过了关键段
- **同义替换未识别**：题目词原文里没有原词，但意思相同

**应对**：

- **用具体名词 / 数字 / 专有名词**作为定位词（这些词通常在原文中原词出现）
- **避免用动词 / 形容词**作为定位词（这些词容易被同义替换）
- **找不到时换关键词**：如 "research" 找不到，换 "study" / "investigation" / "analyse"

### 陷阱 2：同义替换未识别

**症状**：

- 看到选项 / 题目里有原文原词，认为是干扰项
- 实际答案就是这个词的同义替换

**应对**：

- **训练「识别意思不识别字面」**——背词族时背完整词族
- **做真题时建立「同义替换对照表」**（题目词 → 原文词）
- **填空题答案词几乎从不在原文中原词出现**——必须听懂意思

### 陷阱 3：TFNG 误判

**症状**：

- F 误判为 NG（最常见）
- NG 误判为 F（次常见）

**原因**：

- 误以为「未提及」= NG，但实际上是「矛盾」= F
- 误以为「反义替换」= NG，但实际上是「矛盾」= F

**应对**：

- **FALSE 永远是「能找到反义/矛盾」**——必须能在原文中找到对立的表述
- **NOT GIVEN 永远是「信息缺失」**——不是「我找不到」也不是「我不同意」
- **范围篡改 / 程度篡改 / 方向篡改** → F（不是 NG）

**示例**：

> 原文：Rarely do researchers agree.
> 题干：All researchers agree.
> 判定：本题是 F（all vs rarely = 矛盾），不是 NG

### 陷阱 4：过度推理

**症状**：

- 选了一个「合理但未提及」的选项
- 选了一个「原文支持但需要推断」的选项

**应对**：

- **NG 永远是「信息缺失以至于无法证实或反驳」**——不能选需要推断的
- **F vs NG 关键测试**：能否在原文中找到对立的表述？
  - 能 → F
  - 不能 → NG

**示例**：

> 原文：The hotel was hardly impressive.
> 题干：The hotel was very impressive.
> 判定：原文否定 → 题干肯定 → **F**（不是 NG）

### 陷阱 5：Heading 误判

**症状**：

- 选了过宽的标题（覆盖多段）
- 选了过窄的标题（只覆盖某句话）
- 没识别被细节干扰的选项

**应对**：

- **四步法**（详见 `reading-question-types.md` Type 5）：
  1. 预判段落结构
  2. 划出核心话题词
  3. 选项关键词匹配
  4. **反向验证**（所选标题能覆盖 80% 段落内容）

### 陷阱 6：匹配题误判

**症状**：

- 误用选项（用过未划 / 复选未识别）
- 把乱序题当顺序题做（耗时过多）

**应对**：

- **用完即划**（除非题目说「可复用」）
- **乱序题**：先通读选项 → 划关键词 → 扫读原文 → 匹配

### 陷阱 7：填空题错误

**症状**：

- 字数超限（NO MORE THAN TWO WORDS 写 3 个）
- 词性错（"to + 空" 写成名词）
- 拼写错
- 改述原文（应严格用原词）

**应对**：

- **每题先看字数限制**（划出来）
- **预测词性**（空格前 the / a → 名词；to 后 → 动词原形）
- **严格用原词**（不改述）
- **机考提交前检查**（虽然机考 0 分钟 review，但平时训练时强制检查）

### 陷阱 8：粗心

**症状**：

- 看错题号（31 写成 13）
- 抄错（原文 "industrial" 写 "industries"）
- 答案错位（写到错误的题目下方）

**应对**：

- **做每题时同时确认题号**
- **Highlight 标记原文关键句**（避免抄错）
- **机考时 Notes 框与答题框区分清楚**（避免写错位置）

### 陷阱 9：时间管理

**症状**：

- P1 占用过多时间（最难常见错误）
- P3 死磕难题
- 乱序题耗时间

**应对**：

- **严格按 20 分钟 / Passage**（IDP 官方）
- **难题标记 → 跳过 → 回来再战**
- **5 分钟倒数时填完所有 Review 标记题**

### 陷阱 10：中国学生长难句（专项）

**症状**：

- 长难句（25+ 词）看不懂
- 学术词（AWL 词族）不认识
- 跳读习惯（漏关键转折词）

**应对**：

- **长难句拆解 5 步**：
  1. 找主语（找谓语前的名词）
  2. 找谓语（找动词）
  3. 找宾语（找动词后的名词）
  4. 划掉修饰成分（介词短语 / 定语从句 / 状语从句）
  5. 翻译主干，再补充修饰

- **学术词积累**：背 AWL 570 词族（详见 `reading-vocabulary.md`）
- **阅读节奏**：每段至少识别 1 个转折词（but / however / although），不跳读

## 三、错题复盘 4 步法

### 步骤 1：归类（5 分钟）

加载 `reading-traps.md` 10 大陷阱，把每道错题归类：

| 题号 | 错题类型 | 归类 |
|---|---|---|
| 1 | 定位失败 | 陷阱 1 |
| 2 | TFNG 误判 | 陷阱 3 |
| 3 | 过度推理 | 陷阱 4 |
| ... | ... | ... |

### 步骤 2：找原因（10 分钟）

针对每类错题回答：

- **定位失败**：为什么定位词选错？应该用什么词？
- **TFNG 误判**：原文 vs 题干 怎么对照？哪里矛盾？哪里没提及？
- **过度推理**：跳过了哪一步？原文支持到哪一步？
- **Heading 误判**：主旨到底是什么？标题是否覆盖整段？

### 步骤 3：定方案（5 分钟）

每类错题定 1 个行动：

- **定位失败类**：下次找定位词时用「具体名词 / 数字 / 专有名词」
- **TFNG 误判类**：下次用「F-vs-NG 关键测试」自检
- **过度推理类**：下次看到「未提及」立即坚决选 NG
- **Heading 误判类**：下次用「反向验证」检查

### 步骤 4：练补救（30 分钟）

找 3 道同类错题（用 `reading-question-types.md` + `reading-paraphrase.md` 出题），按新方案做一遍。

## 五、中国学生常见问题（专项）

### 1. 词汇深度不足（5000 词以下）

**症状**：

- 看到 AWL 词族不识别
- 看到熟词僻义不会判断

**应对**：

- 背 AWL 570 词族（详见 `reading-paraphrase.md`）
- 背熟词僻义清单（详见 `reading-vocabulary.md` 第二章）
- 每天 15 分钟 + 4 周覆盖基础

### 2. 长难句拆解能力弱

**症状**：

- 25+ 词的长句看不懂
- 嵌套从句 / 倒装 / 强调句识别不出

**应对**：

- 5 步拆解法（见陷阱 10）
- 每天 1 个长难句结构训练（4 周 30 个）
- 阅读 The Economist / Nature 学术文章

### 3. 跳读习惯（漏关键转折词）

**症状**：

- 跳过 "however / but / although" 等转折词
- 漏读关键的反义替换

**应对**：

- 强制识别转折词（每次转折词出现立即 Highlight）
- 读完每段自问「这段有没有转折？转折后是什么？」
- 标记重点转折词（清单贴在书桌前）

### 4. 机考 UI 不熟悉

**症状**：

- 不会用 Highlight / Notes
- 不熟悉左文右题分屏
- 不熟悉屏幕计时器

**应对**：

- 考前 2 次 BC 官方 IELTS Ready Premium 机考模拟
- 熟悉屏幕滚动、字号调节、Help 按钮
- 训练「Highlight 关键词」习惯

### 5. 时间管理失控

**症状**：

- P1 占用过多时间
- P3 死磕难题
- 5 分钟倒数时发现漏题

**应对**：

- **严格 20 分钟 / Passage**
- **每 5 分钟检查一次进度**
- **难题标记 → 跳过 → 回来再战**

### 6. 心态问题（考场上紧张）

**症状**：

- P1 错 2 题后开始慌
- P3 难题紧张导致整段卡住

**应对**：

- **考前 30 秒动作清单演练**（详见 `reading-overview.md`）
- **Reset 心态**：错 2 题是正常的，P3 是用来拉分的
- **跳过难题**：标记 → 跳过 → 回来再战

## 六、错题诊断与突破（按错题数对应表）

| 错题分布 | 问题定位 | 突破方向 |
|---|---|---|
| **P1 错 5+** | 细节定位 / 词性预判 / 拼写 | 精读能力 + 学术词族基础；背 AWL 词族 + 练 `reading-vocabulary.md` 熟词僻义 |
| **P2 错 5+** | 同义替换 / TFNG / 否定触发 | 词族记忆 + TFNG 类型训练 + 否定触发器标注 |
| **P3 错 6+** | Heading / 段落主旨 / 抽象同义替换 | 段落功能训练 + 精读学术文章 + 抽象词族 |
| **TFNG 错 4+** | F vs NG 误判 / 范围篡改未识别 | 加载 TFNG 章节，做 3 套 TFNG 专项 |
| **Heading 错 4+** | 段落主旨偏差 / 选项匹配过宽 | 加载 Heading 章节 + 3 套 Heading 专项 |
| **填空字数超 4+** | 不看字数限制 / 词性预判错 | 强制每题先看「NO MORE THAN...」再做 |

## 七、立刻可做的 3 个动作

1. **打印错题复盘模板**（本章第四节）→ 每次模考后立即用 4 步法复盘
2. **打印 10 大陷阱清单** → 贴在书桌前 → 每次做题前自检
3. **做 1 套完整模考**（IELTS 21 Test 1）→ 按错题分布确定本周主攻方向
