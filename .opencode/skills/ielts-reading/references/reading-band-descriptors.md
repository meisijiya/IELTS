## 四、A vs G 计分对照表（精读）

| Band | A 类所需题数 | G 类所需题数 | 差距 |
|---|---|---|---|
| 3.0 | 4–5 | 9–11 | **+5** |
| 3.5 | 6–8 | 12–14 | **+6** |
| 4.0 | 9–12 | 15–18 | **+6** |
| 4.5 | 13–14 | 19–22 | **+7** |
| 5.0 | 15–17 | 23–26 | **+8** |
| 5.5 | 18–22 | 27–29 | **+7** |
| 6.0 | 23–25 | 30–32 | **+7** |
| 6.5 | 26–29 | 33–34 | **+7** |
| 7.0 | 30–31 | 35 | **+5** |
| 7.5 | 32–34 | 36 | **+4** |
| 8.0 | 35–36 | 37–38 | **+2** |
| 8.5 | 37–38 | 39 | **+2** |
| 9.0 | 39–40 | 40 | **+1** |

**关键洞察**：

- **低分段（3.0–6.5）**：G 类需要多用 5–8 题才能拿到同样的 Band
- **高分段（7.0–9.0）**：差距缩小到 1–5 题（A 类 35-36 题到 8.0，G 类 37-38 题才到 8.0）
- **结论**：**G 类冲 7+ 难度高于 A 类**（G 类 35 题才到 7.0，A 类 30 题就到 7.0，需多 5 题）。G 类设计为「更容易拿到 Band 5–6」（填空题权重高、文本偏短），对低分目标考生有利；但对冲 7+ 考生不利（同样 30 题 A 类 7.0 / G 类 6.0；同样 35 题 A 类 9.0 / G 类 7.0）。

## 五、估分方法

### 步骤 1：基本统计

- 模考总正确数（满分 40）
- 考试类型（A / G）—— **直接影响计分表**
- 各 Passage 正确数（P1 / P2 / P3）

### 步骤 2：查表

- 按 A / G 类查计分对照表
- 估算 Band（考虑 ±1 题浮动）

### 步骤 3：错题类型分布

加载 `reading-traps.md` 10 大陷阱，把错题归类：

| 错题类型 | 占比 | 影响 |
|---|---|---|
| 定位失败 | ___% | 高 |
| TFNG 误判 | ___% | 高 |
| 同义替换 | ___% | 中 |
| Heading 误判 | ___% | 中 |
| 过度推理 | ___% | 中 |
| 填空（字数 / 拼写） | ___% | 低 |
| 长难句 | ___% | 中 |
| 粗心 | ___% | 低 |

### 步骤 4：Passage 弱项诊断

详见 `reading-overview.md` 第八节。

### 步骤 5：升级路径

> 推荐调用 `scripts/study_plan.py --target [目标] --days [天数] --level [当前]`

## 六、估分方法详解

### 估分示例 1：A 类

```
模考成绩：35 / 40
考试类型：A 类 Academic
Band 估算：8.0（35–36 → 8.0）

各 Passage 正确数：
- P1: 13/13（必全对目标达成）
- P2: 12/13（错 1 题 TFNG 误判）
- P3: 10/14（错 4 题 Heading 误判）

错题类型分布：
- TFNG 误判：1 题
- Heading 误判：4 题
- 占比：5/5 错误 = 100% 高级题型

升级路径：
- 重点突破 Heading（80% 错误）
- 次要：TFNG 误判（20% 错误）
```

### 估分示例 2：G 类

```
模考成绩：30 / 40
考试类型：G 类 General Training
Band 估算：6.0（30–32 → 6.0）

各 Section 正确数：
- S1：13/14（错 1 题填空「单复数」）
- S2：11/13（错 2 题匹配）
- S3：6/13（错 7 题 Heading + 复杂匹配）

错题类型分布：
- 填空（单复数）：1 题
- 匹配：2 题
- Heading + 复杂匹配：7 题
- 占比：7/10 错误 = 70% 高级题型

升级路径：
- 重点突破 Heading + 复杂匹配（70% 错误）
- 次要：填充（单复数）+ 匹配（30%）
```

## 七、评分红线

### 1. 不混淆 A vs G

- 用户说 G 类必须按 G 类计分表
- 同样 30 题：A 类 Band 7.0 / G 类 Band 6.0（差 1 档）

### 2. 不吹捧

- 5.5 水平不评 7
- 偏差超过 1 档需明确说明「为什么」

### 3. 明确限制

- 本 skill 基于答案文本评分
- **无法检测用户是否真读懂原文**——只能评估「定位 + 替换识别 + TFNG 判定 + 题型策略」

### 4. 不要套模板

- 每条反馈必须引用具体错题与可能的考点
- 不要给「你应该多背单词」这种空话

### 5. 不要忽略 Passage 3

- P3 是 7+ 拉开差距的关键
- 必须用 Heading / 复杂匹配 / 学术词汇专项测试

## 八、阅读目标分数对应的题型训练重点

| 目标 Band | 必练题型 | 次要题型 |
|---|---|---|
| **5.0–5.5** | P1/P2 填空 + 简单 TFNG + 简单单选 | 短答题 |
| **6.0–6.5** | + 填空（综合） + 中等 TFNG + 句子完成匹配 | 信息匹配 |
| **7.0–7.5** | + Heading + 复杂 TFNG + 复杂匹配 | YNNG + 反义替换 |
| **8.0+** | + 学术阅读拓展 + 段落主旨精读 + 抽象同义替换 | 全部题型均衡 + AWL 5–7 频段 |

## 九、四个 Band 7+ 的关键洞察

### 洞察 1：A 类 Band 7 需要 30 题 → P1 + P2 错 0–4 题 + P3 错 3–6 题

- P1/P2 保底（错 1 题就掉档）
- P3 拉分（Heading + 复杂匹配）

### 洞察 2：A 类 Band 8 需要 35 题 → P1 + P2 必全对（26 题）+ P3 对 9 题

- 真正决定 7→8 的是 P3 的 5–6 题差距
- 但 P1/P2 不允许失分（错 1 题就掉档）

### 洞察 3：G 类 Band 7 需要 35 题 → S1 + S2 必全对 + S3 错 0–5 题

- G 类 S3 相对 A 类 P3 简单
- S1 填空题权重高（容易拿分）

### 洞察 4：Band 7+ 学员必须掌握平行阅读法（虽然非官方推荐）

- 顺序题已基本掌握
- Heading / 复杂匹配需要「一次读 P3 全部题目 → 回原文找」的高效策略
- ⚠️ 本 skill 标注为**民间策略**，学员可按自己节奏决策
