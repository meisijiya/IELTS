## 二、🆕 2026 年中期全球转机考（阅读部分）

### 官方公告

> "From mid-2026, we will no longer offer IELTS as a paper-based test. All IELTS tests will be delivered on computer."
> ——IELTS 官方 2026-03-05

**含义**：

- 2026 年中期起**全球停办纸笔考**
- 所有考生默认走 IELTS on Computer
- 部分市场保留 **"Writing on Paper"** 选项（机考完成听/读/说，手写作文）
- **Writing on Paper 选项不适用于阅读**——BC 页面明文「The Listening and Reading components will still be taken on computer」

### 阅读部分的实操差异

| 项目 | 纸笔考（即将停办） | **机考（2026 默认）** |
|---|---|---|
| 文本 UI | 试卷（文本 + 题目分开两本） | **左文右题分屏**（文本在左，题目在右） |
| 文本标记 | 笔做标记 | **Highlight 高亮** + **Notes 批注** |
| 字号 | 固定 | **字号可调** |
| 计时器 | 老师喊 | **屏幕计时器**（最后 10/5 分钟闪烁） |
| 誊写缓冲 | 0（**阅读不论纸笔或机考都没有**） | 0（**阅读不论纸笔或机考都没有**） |
| 跨段滚动 | 翻页 | **滚动条** |
| 导航 | 翻页 | **40 题导航条**（可 jump） | 
| 词典 | 自带纸质词典 | **没有内置词典**（无官方依据） |
| 复制粘贴 | —— | **部分中国考场禁用 Ctrl+C/Ctrl+V**（民间一致报道，官方未明确披露）|

### 训练方法变化（核心）

**初稿「机考 vs 纸笔二选一」已过时**——2026 年中期全球停办纸笔考，所有考生默认机考。

**机考阅读训练三原则**：

1. **左文右题分屏习惯**：用 BC 官方 IELTS Ready Premium 做 2 次全真机考模考，熟悉 UI
2. **Highlight 关键词定位**：每题先看题目 → Highlight 题目关键词 → 在原文中搜 → 定位答案区间
3. **屏幕计时器管理**：每 5 分钟检查一次进度（P1 是否已结束 / P2 是否进入）

### 关键事实澄清（必读）

**初稿错误**：「阅读机考需要 2 分钟 review」

- **正确事实**：阅读不论纸笔还是机考都「no extra transfer time」——60 分钟内完成答卷，没有誊写缓冲。
- 2 分钟 review 是**听力的机考规则**，**不是阅读**。来源：[ielts.org Academic Reading Format](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-reading)（核验 2026-08-17）。
- **本 skill 主 SKILL.md 初稿（已修正）** 提醒：阅读与听力的「2 分钟 review」混淆是常见错误。

### 机考常见问题与应对

| 问题 | 应对 |
|---|---|
| 屏幕小分屏字体小 | 调大字号（设置按钮） |
| 屏幕题量大 | 考前 2 次 BC 官方机考模拟 |
| 时间压力大 | 每 5 分钟检查进度，严格按 20 分钟 / Passage |
| 没内置词典 | 提前背 AWL 词族 + Oxford 5000 基础词 |
| 不确定答案 | Review 标记（题号变圆形）→ 60 秒内返回 |

### Writing on Paper 选项

部分市场提供：

- 机考完成听/读/说 + 手写作文
- 适合「打字慢但写字稳」的考生
- **阅读部分不受影响**——仍必须在机考阅读区完成

## 三、🆕 One Skill Retake (OSR) 阅读单科重考

### 什么是 OSR

**One Skill Retake (OSR)** 是 IELTS 自 2022 年末推出的「单项重考」政策，允许考生在原考日起 60 天内单独重考**听/读/写/说**任一科目。

### 2026 OSR 规则（关键事实）

| 项目 | 详情 |
|---|---|
| **可用科目** | Listening / Reading / Writing / Speaking **全部 4 项**（包括阅读） |
| **时间限制** | 原考日起 **60 天内** 完成 OSR |
| **考试方式** | **必须机考**（IELTS on Computer 全套） |
| **每次限制** | 每次全考只能 OSR 一次 |
| **IELTS Online** | ❌ **不支持 OSR**（仅机考中心支持） |
| **覆盖范围** | **1200+ 机构接受**（IDP 官方数据，"widely available worldwide"——具体国家覆盖因市场而异；**美国不接受 OSR**） |
| **2026 起 WoP 衔接** | 若考生原选 Writing on Paper，OSR 重考时**必须仍用 WoP** |

### 阅读 OSR 流程

1. **原考**（A 类 / G 类任一）→ 拿到成绩单
2. **60 天内** → 申请 OSR 仅重考阅读
3. **60 天内** → 在 OSR 考点完成**仅阅读部分**（与听力无关，单独计时 60 分钟）
4. **新 TRF** → 收到新 Test Report Form（包含原 L/R/W/S + 新 Reading 分数，重新计算 overall band）
5. **选择成绩单** → 候选人自己选择用原 TRF 还是新 TRF

### 阅读 OSR 后是否影响最终成绩单 OSR 标记

**官方依据**（[ielts.idp.com OSR Results](https://ielts.idp.com/prepare/article-ielts-one-skill-retake-osr-results-trf)，2023-10-22，核验 2026-08-17）：

> "You will receive a new IELTS Test Report Form, which includes your new IELTS One Skill Retake result as well as the results from the previous skills you did not retake. … You can choose whether you use your original TRF or your new TRF. … The OSR TRF will also have an overall band score, which is the average of the three original scores and the score from the retaken skill."

**事实核验**：

- ✅ 完成 OSR 后会收到**新 TRF**（含原 3 项 + 新阅读分数）
- ✅ 候选人自己选择使用原 TRF 还是新 TRF
- ⚠️ **TRF 上是否有「OSR」字样、戳记或脚注**——ielts.org / BC / IDP 三个官方渠道均**未提及**。**无法核实**——需查看 TRF 实物原件。

### 何时考虑阅读 OSR

**适合阅读 OSR 的情况**：

- ✅ 阅读 < 6.5 但其他科 ≥ 7
- ✅ 阅读明显失常（如平时模考 7+ 但考试只 5.5）
- ✅ 因时间分配失误导致 P1 用时过多 / P3 没来得及做完
- ✅ 申请截止日期宽裕（OSR 前后间隔 < 60 天 + 7 天强化）

**不适合阅读 OSR 的情况**：

- ❌ 整体水平都低（如全科 < 6）—— 应整体重考而非 OSR
- ❌ 阅读是长期弱项——需要时间系统提升，OSR 救不了
- ❌ 申请截止日期紧——OSR 前后需 1–2 周准备
- ❌ 考试机构不接受 OSR（少数机构仅认首次成绩）

### 阅读 OSR 前 7 天强化方案

如决定 OSR，按以下 7 天计划强化：

| 天 | 任务 |
|---|---|
| **Day 1-2** | 1 套完整真题模考 + 错题分析（识别阅读最弱题型） |
| **Day 3-4** | 专攻最弱题型，做 5 套该题型专项练习 |
| **Day 5-6** | 2 套完整真题模考（计时 + 机考 UI 模拟） |
| **Day 7** | 1 次全真模拟 + 考前 30 秒动作清单演练 + 作息调整 |

调用 `scripts/study_plan.py --target 7 --days 7 --level 6` 可自动生成 7 天计划。

### 阅读 OSR 重要提示

- OSR 报名后**必须在 60 天内完成**——过期作废
- OSR 成绩与原成绩独立，但**取最高**计入最终成绩
- 部分机构**只认 OSR 成绩**或**只认首次成绩**——报名前必须确认目标机构政策
- OSR 不是「免死金牌」——阅读仍是 60 分钟 + 3 个 Passage + 40 题，不会更简单

## 五、🆕 官方 11 大题型 vs 民间「10 大题型 / 13 大题型」

### 官方分类（ielts.org + cambridgeenglish.org）

**ielts.org 官方分类**（11 大类，Type 1–11）：

| Type | 名称 |
|---|---|
| 1 | Multiple choice |
| 2 | Identifying information (True/False/Not given) |
| 3 | Identifying writer's views/claims (Yes/No/Not given) |
| 4 | Matching information |
| 5 | Matching headings |
| 6 | Matching features |
| 7 | Matching sentence endings |
| 8 | Sentence completion |
| 9 | Summary/note/table/flowchart completion（合并） |
| 10 | Diagram label completion |
| 11 | Short-answer questions |

**Cambridge IELTS 19/20/21 前言分类**（14 项合并列举）：

> "A variety of question types is used, including: multiple choice, identifying information (True/False/Not Given), identifying the writer's views/claims (Yes/No/Not Given), matching information, matching headings, matching features, matching sentence endings, sentence completion, summary completion, note completion, table completion, flowchart completion, diagram-label completion and short-answer questions."

**关键差异**：

- ielts.org Type 9 = Cambridge「summary completion + note completion + table completion + flowchart completion」合并
- Cambridge 把 sentence completion 单列（对应 ielts.org Type 8）

### 民间分类（无官方依据）

| 民间说法 | 实际来源 | 状态 |
|---|---|---|
| 「10 大题型」 | 中国民间培训资料 | **无官方依据**——通常是合并 TFNG/YNNG 或省去 diagram label |
| 「13 大题型」 | 中国民间培训资料 | **无官方依据**——通常是把官方 Type 9 拆成 4 个 + sentence completion 单列 |

**结论**：雅思官方（ielts.org / cambridgeenglish.org / Cambridge IELTS 系列前言）**只有两套表述**——「11 大类」与「14 项合并列举」。**初稿「10 大题型」应修正为「11 大类」或「14 项合并」**。

## 六、🆕 TFNG / YNNG 三类定义的官方表述

### 官方定义（True / False / Not Given）

> "**'False'** means that the statement **contradicts the information in the text**. **'Not given'** means that the statement **neither agrees with nor contradicts the information in the text**. You must be careful not to use any information you already know about the topic of the text when choosing your answer."
>
> — [cambridgeenglish.org Test Format](https://www.cambridgeenglish.org/exams-and-tests/ielts/test-format/) | [ielts.org Academic Reading Format](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-reading)

### 官方定义（Yes / No / Not Given）

> "**'No'** means that the statement **contradicts the writer's view or claim**. **'Not given'** means that the statement **neither agrees with nor contradicts the writer's view or claim**."

### 民间说法 vs 官方表述

| 民间说法 | 官方原文 | 准确性 |
|---|---|---|
| True = 题干与原文**同义** | 「statement agrees with the information」 | ✅ 一致 |
| False = 题干与原文**直接矛盾** | 「statement contradicts the information」 | ✅ 一致 |
| Not Given = 题干与原文**未提及** | 「statement neither agrees with nor contradicts」 | ⚠️ **不精确**——官方原意为「信息缺失以至于无法证实或反驳」；IDP 官方解释为「no information on this」作为操作性表述，因此「未提及」在应试层面可接受 |

### 关键区分（官方明文）

- **True / False / Not Given**（Type 2）评估**事实信息**（factual information）
- **Yes / No / Not Given**（Type 3）评估**作者观点 / 主张**（writer's views/claims）

**民间常见错误**：把 TFNG 与 YNNG 混淆——评估对象不同（事实 vs 观点）。详见 `reading-question-types.md` Type 2/3 章节。

## 七、🆕 A 类 vs G 类阅读官方差异

### 关键事实（纠正民间说法）

| 维度 | A 类 Academic | G 类 General Training |
|---|---|---|
| **Sections 数** | 3 | **3**（不是民间说的 5 个！） |
| **文本结构** | 3 个长文本 | S1 含 2–3 个短文本，S2 含 2 个文本，S3 含 1 个长文本 |
| **文本总长** | 2,150–2,750 词 | 2,150–2,750 词 |
| **题数** | 40 | 40 |
| **时长** | 60 分钟 | 60 分钟 |
| **题型数** | 11 大类 | 11 大类（**与 A 类一致**） |
| **难度分布** | **Band 5–8 题占比多** | **Band 3–6 题占比多** |
| **Band 5 所需题数** | 15 | **23** |
| **Band 7 所需题数** | 30 | **35** |

### 民间说法的核验

**❌ 民间说法**：「G 类阅读有 5 个 Section」

**✅ 官方事实**：G 类 3 个 Sections。具体来源：

- [ielts.org GT Reading Format](https://ielts.org/take-a-test/test-types/ielts-general-training-test/ielts-general-training-format-reading)（2024-07-08 更新）：
  > "There are **three sections of increasing difficulty**. Section 1 may contain two or three short texts or several shorter texts. Section 2 contains two texts. In Section 3, there is one long text."

**❌ 民间说法**：「A 类比 G 类简单」

**✅ 官方事实**：

- A 类 Band 5–8 题占比多（高分难度）
- G 类 Band 3–6 题占比多（低分难度）
- 同样 Band 5.0：A 类 15 题 / G 类 23 题
- **民间说"简单"是因为填空题更多、文本更短，但官方设计 G 类是为了「更容易拿到 Band 5–6」**——这对低分目标考生有利，但对冲 7+ 考生不利（因为同样的 30 题只能拿 Band 6.0）。

来源：[ielts.org Scoring in detail](https://ielts.org/take-a-test/your-results/ielts-scoring-in-detail) | [BC IELTS Guide for Teachers PDF](https://takeielts.britishcouncil.org/sites/default/files/ielts_guide_for_teachers.pdf)

### G 类训练要点

- **填空题权重高**：P1 短文本填空多（图例填空 Type 10 / 摘要填空 Type 9 / 短答题 Type 11）
- **学术词汇要求低**：G 类 P3 相对 A 类 P3 难度低
- **日常话题为主**：广告、招聘、规章、说明书类文本多
- **不需要大量学术词汇**：不需要像 A 类那样背 AWL 570 词族，但 Oxford 3000 词族建议全覆盖

### 中国考场（chinaielts.org）

- 2025-09-01 起中国大陆普通 IELTS 停办纸笔，全部机考；UKVI 从 2025-07-01 起停办纸笔
- 阅读：原文与题目**左右分屏显示**
- **Highlight** 与 **Notes** 功能可标记关键词和核心信息
- 字体大小可灵活调节

来源：[chinaielts.org 机考模式](https://www.chinaielts.org/about-ielts/ways-to-take-ielts/computer)

### 「Right-click 词典」在中国考场是否被禁用

**官方依据**：

- ❌ ielts.org / British Council / IDP / chinaielts.org **均未在官方功能列表中提到「right-click 词典」或「内置词典」功能**
- 官方列出的功能仅：highlight、notes、font adjustment、scroll、navigation、timer、help、review

**民间说法**：

- [环球雅思 2026-08-05](https://www.jiaoyubao.cn/news/n374967.html)：「填空题虽然支持从原文复制粘贴，但要注意：**部分考场禁用 Ctrl+C/Ctrl+V快捷键**，只能用鼠标右键操作。」——民间提示存在「考场禁用快捷键」现象

**结论**：

- **「Right-click 调出词典」无法核实为机考标准功能**。ielts.org / BC / IDP 官方文档均未列「内置词典」功能
- 中国部分考场对 **Ctrl+C / Ctrl+V 复制粘贴有禁用**——民间报道一致，但**官方未明确披露**禁用规则
- 民间「右击词典」说法可能源自对「右键 → Highlight / Notes」功能的误读，建议按官方说明理解

## 九、🆕 三大民间说法纠正（核心）

### 9.1 「近 500 组同义替换高频词」

**事实**：**无任何官方数据支持该数字**。

**官方相关资源**（均为公开学术资料，非 IELTS 官方）：

- **AWL（Academic Word List, Coxhead 2000）**：570 词族
- **BNC/COCA word family lists**（Nation）：最高频 1k 至 25k 分级
- **Oxford 3000 / 5000**（OUP）：按 CEFR 分级
- **General Service List (West, 1953)**：约 2,000 词族

⚠️ **核验结论**：「近 500 组同义替换」这一说法**未在 IELTS Partners（ielts.org / BC / IDP / Cambridge）任何官方资料中出现**，也没有可对应的学术权威出处。**疑似夸大或营销话术**。

**修正建议**：

- 改用 **AWL 词族（Coxhead 2000）570 词族**作为底层词汇
- 不引用「近 500 组」类似数字
- 详见 `reading-paraphrase.md` 修正章节

### 9.2 「5 大梯队难度递进」

**事实**：**无官方依据**。

**官方相关表述**：

- IELTS 9 个 Band（0–9）有官方 band descriptors
- BC 教师指南指出 A 类与 G 类在难度分布上的差异（bands 5–8 vs 3–6）

**民间「5 大梯队」**：常见分法为「Band 4 / 5 / 6 / 7 / 8 五档」——这是 **第三方对 9 个 Band 的主观合并**，**非官方分类**。雅思官方始终使用 0–9 共 10 个 Band 表述。

⚠️ **核验结论**：「5 大难度梯队」无任何官方依据，**属于民间培训机构的归类**。

**修正建议**：

- 改用 **9 个 Band（0–9）连续量表**
- 不合并为 5 档
- 详见 `reading-overview.md` 第四节计分对照表

### 9.3 「平行阅读法」

**事实**：**非官方推荐方法**。

**官方方法表述**（IDP 官方）：

> "You have 60 minutes to complete 40 questions on the test, so managing your time is crucial. There are three sections in the Reading test, and you should aim to **spend no more than 20 minutes on each section**. As the test progresses, the sections increase in difficulty, so make sure you allow yourself enough time to complete each section."
>
> — [ielts.idp.com Time Management](https://ielts.idp.com/prepare/article-how-to-manage-your-time-during-the-ielts-test)

> "**Read the questions before you read the text**"
>
> — IDP 官方推荐

**学术依据**（Weir et al. 2009 PDF）：

- 高分组考生倾向于 "quickly match words in the question with similar or related words in the text"（83% 使用）+ "read relevant parts of the text again"（77%）
- 该研究是**对考生自然策略的描述**，**非官方「做题顺序」建议**

⚠️ **核验结论**：

- 「平行阅读法」（如「一次性先读 P1+P2+P3 所有题目再分别回文找答案」）——**无任何官方依据**
- 官方推荐是：**按 Section 顺序做，每 Section 20 分钟，先看题再读文章**（IDP 官方表述）
- Weir 2009 学术研究描述考生真实策略，但未推荐任何「平行」做法

**修正建议**：

- 本 skill **保留平行阅读法作为民间可选策略**，但**明确标注非官方推荐**
- 默认推荐 **顺序阅读法**（IDP 官方）
- 详见 `reading-strategies.md` 第一节

## 十、🆕 2024-2026 阅读趋势（题型 + 话题）

### 题型分布变化

**官方事实**：剑桥 19 / 20 / 21 系列前言对题型的表述完全一致——**官方未声明「题型分布」在 19–21 间有调整**。

**第三方学术分析**（ERIC EJ1239132 "A Comparability Study"）：

- 4 套平行 Academic IELTS 阅读卷中：
  - Matching 占 50% / 47.7%（最高）
  - Blank-filling（填空）占约 25–38%
  - Multiple choice 占 11–22%
  - Short-answer 题基本为 0%

**Cathoven 民间分析**（[resources.cathoven.com](https://resources.cathoven.com/ielts-reading/matching-headings)）：

> "Matching headings questions appear in roughly **60%** of Academic Reading tests, according to analysis of Cambridge IELTS official practice volumes 1–18."

⚠️ **核验状态**：上述 60% / 50% / 47.7% 均为 **第三方 / 民间分析**，**非 IELTS 官方数据**。ielts.org 的 Research Reports Online 系列无公开「按卷统计的题型占比」。

### 话题趋势（Cambridge 19/20/21 部分样本）

| 卷次 | Test 1 阅读话题一览 |
|---|---|
| **Cam 19 T1** | 网球拍演进 / 古地中海海盗 / 错误信息的持久性与风险 |
| **Cam 20 T1** | 鸮鹦鹉（kākāpō）/ 英国榆树回归 / 压力如何影响判断 |
| **Cam 21 T1** | Davies 姐妹艺术品收藏 / **噪音与沉默的健康研究** / 全球糖业史 |

**事实**：Cam 21 Test 1 中 P2 是关于「沉默（silence）/ 噪音暴露」对健康影响——与「AI、气候、神经科学」等热门话题属同类（健康 / 环境 / 心理）。但官方未声明话题分布有「AI / 气候 / 神经科学」等定向趋势。

⚠️ **无法核实**：民间常说「近期常考 AI / 气候 / 神经科学」——**官方无数据**支持具体话题比例。仅有上述 Cambridge 19 / 20 / 21 部分 Test 1 样本可供参考。

### 难度变化

**事实**：ielts.org 与 British Council 教师指南明确：所有试卷在投放前都经过预试与等值化（equating）。

> "Although all IELTS test materials are pretested and standards fixed before being released as live tests, there are probably minor differences in the difficulty level across tests. To equate different tests, the band score boundaries are set so that all test takers' results relate to the same scale of achievement."
>
> — [BC IELTS Guide for Teachers](https://takeielts.britishcouncil.org/sites/default/files/ielts_guide_for_teachers.pdf)

**结论**：官方层面「难度」通过等值化（equating）保持一致；不存在官方「难度递增」的政策声明。

## 十一、🆕 AI 监考（2024 起强化）

**事实**（与 listening/writing 一致）：

- IDP / British Council 自 2024 年起对**口语、写作**实施监考级 AI 检测
- **阅读部分**目前未见官方明确披露 AI 检测机制（仅民间报道 IDP/BC 监考摄像头覆盖全场，**未明确检测阅读答题内容**）
- **本 skill 仅用于教学、训练、提纲、错题分析与范例示例**，**禁止**作为代考工具

⚠️ **合规红线**：

- 不为考生提供「代答」「机器翻译 + 改写」「AI 实时生成答案」等代考服务
- 出题时明确标注「仿某 Passage 风格」（不伪造真题）
- 评分时明确告知「基于文本评分，无法检测真实阅读能力」
